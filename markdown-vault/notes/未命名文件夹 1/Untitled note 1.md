# 1 扩展SLIP模型与总体控制框架

## 1.1 含车轮动力学的扩展SLIP模型

经典SLIP模型将机器人简化为集中质量和无质量弹性腿，能够描述跳跃过程中的压缩储能与伸展释能，但未考虑车轮转动及轮地滚动约束[2]。为描述两轮足机器人的轮腿耦合特性，本文在SLIP模型基础上引入车轮转动动力学，构建弹簧—质点—车轮耦合模型，如图1所示。

设机身质心位置为 `\boldsymbol p_b=[x_b,z_b]^{\mathrm T}`，第 `i` 个轮心位置为 `\boldsymbol p_{w,i}`，其中 `i\in\{L,R\}`。虚拟腿长及其方向向量分别为

```math
L_i=\left\|\boldsymbol p_b-\boldsymbol p_{w,i}\right\|, \qquad \boldsymbol e_i= \frac{\boldsymbol p_b-\boldsymbol p_{w,i}}{L_i}. \tag{1}
```

虚拟腿轴向作用力表示为

```math
F_{L,i} = K_L^{(s)} \left(L_{0,i}^{(s)}-L_i\right) -D_L^{(s)}\dot L_i +F_{\mathrm{ff}}^{(s)}, \tag{2}
```

式中：`L_{0,i}^{(s)}`为相位 `s` 下的参考腿长；`K_L^{(s)}`和 `D_L^{(s)}`分别为相位相关的虚拟刚度和阻尼；`F_{\mathrm{ff}}^{(s)}`为支撑前馈力。通过改变不同跳跃相位下的参考腿长、刚度和阻尼，可分别实现下蹲蓄能、爆发蹬伸和着陆缓冲。

第 `i` 个车轮的转动动力学为

```math
J_{w,i}\dot{\omega}_{w,i} = \tau_{w,i} -b_{w,i}\omega_{w,i} -r_wF_{x,i}, \tag{3}
```

式中：`J_{w,i}`为车轮转动惯量；`\omega_{w,i}`和 `\tau_{w,i}`分别为车轮角速度和驱动力矩；`b_{w,i}`为等效转动阻尼；`r_w`为车轮半径；`F_{x,i}`为轮地切向作用力。在支撑阶段，理想纯滚动约束可写为

```math
v_{x,i}^{c}=r_w\omega_{w,i}, \tag{4}
```

其中 `v_{x,i}^{c}`为轮地接触区域的切向速度。腾空阶段轮地作用力为零，但车轮加减速产生的反作用力矩仍会影响机身俯仰姿态。因此，扩展模型在腿部弹性运动之外，同时考虑车轮旋转对起跳和着陆过程的影响。

为减小着陆瞬间的轮地速度失配，根据起跳时刻的水平运动状态估计着陆切向速度 `v_{x,i}^{\mathrm{pre}}`，并生成飞行阶段车轮前馈角速度

```math
\omega_{\mathrm{ff},i}(t) = \frac{v_{x,i}^{\mathrm{pre}}}{r_w}\sigma(t), \qquad \sigma(t)= \operatorname{clip} \left( \frac{t-t_{\mathrm f}}{T_{\mathrm f}},0,1 \right), \tag{5}
```

式中：`t_{\mathrm f}`为进入腾空相的时刻；`T_{\mathrm f}`为轮速过渡时间；`\sigma(t)`为平滑斜升系数。该前馈量使车轮角速度在腾空阶段逐渐接近预期着地速度，降低触地瞬间的切向速度突变。与已有W-SLIP和NW-SLIP轨迹规划方法[3,5]不同，本文将扩展SLIP模型作为强化学习控制器的结构先验，其输出仍可由策略根据机器人实际状态进行残差修正。

## 1.2 六状态跳跃有限状态机

根据SLIP模型的压缩—伸展—腾空运动规律，将一次完整跳跃划分为待机、下蹲、蹬伸、腾空、备降和缓冲6个状态。有限状态机状态定义为

```math
s_t\in\{-1,0,1,2,3,4\}. \tag{6}
```

各状态对应的虚拟腿参考和车轮行为见表1。

**表1　六状态有限状态机**

| 状态阶段虚拟腿参考车轮行为主要转换条件 |    |                  |           |               |
| ------------------- | -- | ---------------- | --------- | ------------- |
| `-1`                | 待机 | 保持站立腿长           | 平衡控制      | 跳跃指令持续0.10 s  |
| 0                   | 下蹲 | 压缩至0.24 m        | 制动稳定      | 驻留0.50 s      |
| 1                   | 蹬伸 | 伸展至0.50 m        | 提供辅助冲量    | 驻留0.30 s或双轮离地 |
| 2                   | 腾空 | 由0.26 m过渡至0.42 m | 轮速向着地目标过渡 | 机身下降且接近地面     |
| 3                   | 备降 | 保持0.42 m         | 匹配着地切向速度  | 检测到双轮着地       |
| 4                   | 缓冲 | 由0.42 m压缩至0.30 m | 恢复平衡控制    | 驻留0.15 s后返回待机 |

状态转换同时采用时间条件和本体状态条件。时间条件保证训练初期策略尚未形成有效动作时，仍能够遍历完整跳跃序列；机身高度、垂向速度和轮地接触等状态条件则用于根据实际运动提前进入备降或缓冲阶段。FSM状态及其归一化计时器同时输入策略网络，使相同机器人姿态在不同跳跃阶段能够对应不同控制动作。

## 1.3 分层闭环控制框架

本文控制框架由扩展SLIP-FSM、PPO残差策略和相位自适应VMC组成。扩展SLIP-FSM根据跳跃指令和机器人状态输出虚拟腿长参考 `L_{\mathrm{FSM}}`及车轮前馈角速度 `\omega_{\mathrm{ff},i}`；PPO策略根据历史本体观测和当前相位输出虚拟腿角、髋滚转角、腿长残差及车轮速度残差：

```math
\boldsymbol u_{\pi} = [ \phi_L^d,\theta_L^d,\Delta L_L,\Delta\omega_{w,L}, \phi_R^d,\theta_R^d,\Delta L_R,\Delta\omega_{w,R} ]^{\mathrm T}. \tag{7}
```

其中，左右虚拟腿期望长度为

```math
L_i^d = \operatorname{sat}_{[L_{\min},L_{\max}]} \left[ L_{\mathrm{FSM}}(s_t,\dot z) +g_L\Delta L_i \right], \qquad g_L=0.35, \tag{8}
```

车轮期望角速度为

```math
\omega_{w,i}^d = \operatorname{sat}_{[-\omega_{\max},\omega_{\max}]} \left[ \omega_{\mathrm{ff},i} +g_w\Delta\omega_{w,i} \right]. \tag{9}
```

式中：`g_L`和 `g_w`分别为腿长及轮速残差增益；饱和函数用于限制策略对结构化参考的修正范围。相位自适应VMC根据期望虚拟腿长和腿角计算虚拟力与力矩，并通过雅可比转置映射为髋、膝关节力矩；车轮速度目标则由PI控制器转换为驱动力矩。

该分层结构中，扩展SLIP-FSM负责生成跳跃相位和基础参考，PPO策略负责补偿模型误差及接触扰动，VMC负责虚拟腿力矩执行。三者分别解决“何时动作”“如何修正”和“如何施力”的问题，从而降低端到端策略直接探索完整跳跃时序的难度。这样的架构
