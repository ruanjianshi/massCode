```markdown
# 代码评审与发布检查清单

## A. 编译与静态检查

- [ ] 目标工具链全量编译成功。
- [ ] 开启团队约定的 warning 等级，无新增警告。
- [ ] 静态分析问题已处理或留有可追溯的抑制理由。
- [ ] Debug/Release、不同优化级别及 LTO 配置均已验证。
- [ ] 地址、寄存器、DMA 缓冲区未因编译优化或链接回收丢失。

## B. 架构与接口

- [ ] 应用层没有新增 HAL、寄存器或板级引脚依赖。
- [ ] 硬件资源位于 Board/Device Tree/config，没有散落魔法数字。
- [ ] Bus 与 Client 责任分离，共享总线有统一互斥。
- [ ] 新增抽象确实隔离变化，不是空转发。
- [ ] 同步/异步、阻塞性、超时、回调上下文和所有权已写入接口契约。
- [ ] 公共头文件未泄漏不必要的私有结构。

## C. 参数、边界和错误

- [ ] 所有外部指针、长度、索引、枚举和整数运算已检查。
- [ ] 零长度、最大长度、越界长度和回绕已测试。
- [ ] 每个返回值已处理，错误未被静默吞掉。
- [ ] 必选 ops 在注册时检查，可选 ops 有确定的降级行为。
- [ ] 故障日志包含设备、操作和原始错误，高频日志有限频。
- [ ] 断言只用于内部不变量，外部故障不依赖断言处理。

## D. 内存与生命周期

- [ ] 每个资源的创建者、所有者和释放者明确。
- [ ] 成功、失败、超时和取消路径均释放已获取资源。
- [ ] 无 VLA、`alloca`、无界递归和不受控的大局部变量。
- [ ] 任务栈高水位已在最坏负载下测量。
- [ ] 回调、定时器、DMA 和延迟工作不会访问已销毁对象。
- [ ] 内存泄漏、重复释放和越界已使用适用工具或哨兵测试。

## E. 并发与实时性

- [ ] 所有共享可变状态都有明确保护策略。
- [ ] ISR 仅做最少工作，不分配、不阻塞、不进入复杂业务。
- [ ] 锁顺序统一，外部回调不在内部锁下执行。
- [ ] 临界区有界且经过测量。
- [ ] 所有硬件等待有超时，无永久轮询。
- [ ] 优先级、中断优先级、队列深度和最坏延迟有测量依据。

## F. 硬件、DMA 与 Cache

- [ ] 寄存器地址、位域、访问宽度、`volatile` 和读改写顺序已核对手册。
- [ ] 已检查芯片 Errata 与当前 HAL 版本实现。
- [ ] DMA 缓冲区位于可访问内存，对齐和长度符合要求。
- [ ] TX Clean、RX Invalidate 和 cache-line 边界处理正确。
- [ ] DMA/总线错误能停止、清理、重启并上报。
- [ ] 断线、器件缺失、总线占用、噪声、超时和电源波动已覆盖。

## G. 系统测试与发布证据

- [ ] 单元测试覆盖正常路径和主要错误路径。
- [ ] 已进行满负载、长时间、频繁启停和时间回绕测试。
- [ ] 已执行故障注入，且恢复次数有上限。
- [ ] 看门狗、安全状态、重启原因和持久化故障记录已验证。
- [ ] map 文件中 Flash/RAM/栈/堆余量满足项目门限。
- [ ] 版本、配置、工具链、硬件版本和测试报告可追溯。
- [ ] 回滚或安全升级路径已实机验证。

## H. 变更影响分析

- [ ] 已查找所有调用者、被调用者、回调注册点和配置来源。
- [ ] 已检查结构布局、枚举值、错误码和持久化格式的兼容性。
- [ ] 已确认新代码的执行上下文和优先级。
- [ ] 已补充或更新测试、文档和诊断信息。
```
