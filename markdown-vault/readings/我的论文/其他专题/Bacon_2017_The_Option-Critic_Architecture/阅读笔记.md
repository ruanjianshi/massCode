# Bacon 2017｜Option-Critic 架构（AAAI，分层 RL 理论基石）

## 📋 基本信息

- **作者:** Pierre-Luc Bacon, Jean Harb, **Doina Precup**（McGill / Mila；Precup 即 1999 年选项框架原始论文 `sutton1999` 的共同作者）
- **文章类型:** AAAI 2017，9 页（arXiv v2 于 2016-12）
- **实验:** 四房间导航（tabular）、Pinball（连续状态）、**Arcade Learning Environment**（Asterix / Ms. Pacman / Seaquest / Zaxxon）
- **引用量:** 2000+（分层 RL 三大经典之一）

## 🎯 研究目标

在**不使用子目标（subgoal）、伪奖励（pseudo-reward）或任何先验规范**的条件下，**端到端**地同时学习：

1. **内选项策略（intra-option policy）** `π_ω(a|s)`
2. **终止函数（termination function）** `β_ω(s) → [0,1]`
3. **选项间策略（policy over options）** `π_Ω(ω|s)`

作者在摘要中的原话立场（转述需精确）：**现有的选项学习方法在从单一任务学习时慢得多，其收益大多来自于在相似任务中复用已学到的选项**；相比之下，本文方法能够**在单一任务内成功学习选项而不引入任何减速**，同时仍为迁移学习带来收益。

> ⚠️ 注意区分两件事：「不需要额外奖励或子目标」是本文的**方法特性**（摘要原文：without the need to provide any additional rewards or subgoals）；「现有方法在单任务上慢」是本文对**基线的批评**。二者不要混为一句。

### 作者对「需要什么先验」的精确表述（引言原文，务必按此引用）

> 与其他方法相反，**我们只需要指定期望的选项数量（we only need to specify the number of desired options）**；不需要子目标、额外奖励、示范、多个问题或任何其他特殊安排（**不过，若有需要，该方法也可以利用伪奖励函数**）。据我们所知，这是第一个端到端的方法……

> ⚠️ 这段话有两个对你很重要的含义：
> 1. **选项数需预先指定**——你的 7 个专家也是预先指定，**这一点上两者相同，不要误写成你的优势**；
> 2. 作者**并不排斥伪奖励**，只是不依赖它（原文括号明确写了“若有需要可以利用”）。因此
>    “你用专属奖励就违背了 Option-Critic 的立场”这一质疑其实比看起来更弱——
>    Theorem 1 的对比针对的是「假定选项目标**仅仅**是达成某个子目标」的方法，而非任何使用伪奖励的方法。
>    **你在第 7 章的回应可据此写得更从容，不必过度防守。**

## 🔧 方法

### 选项的形式化与调用-返回执行模型

选项 ω 由 `⟨π_ω, β_ω⟩` 构成：`π_ω` 为内选项策略，`β_ω: S → [0,1]` 为终止函数。

采用 **call-and-return 执行模型**：智能体按 `π_Ω` 选择一个选项，然后**一直遵循 `π_ω` 直到终止**（由 `β_ω` 决定），随后重复此过程。

关键结构性观察（原文）：

> `(s, ω)` 对构成了一个**增广状态空间（augmented state space）**。

状态-选项对上的马尔可夫链转移：
```
P(s_{t+1}, ω_{t+1} | s_t, ω_t) = Σ_a π_{ω_t,θ}(a|s_t) P(s_{t+1}|s_t,a) ·
    [ (1 − β_{ω_t,ϑ}(s_{t+1}))·1_{ω_t = ω_{t+1}} + β_{ω_t,ϑ}(s_{t+1})·π_Ω(ω_{t+1}|s_{t+1}) ]
```

作者证明该过程是**齐次（homogeneous）**的，在适当条件下**遍历（ergodic）**，因而**状态-选项对上存在唯一的平稳分布**。

> ★★★★ 注意这个"平稳分布"的成立条件——它是在**参数固定**的前提下对马尔可夫链而言的。而在实际的联合学习中，θ 与 ϑ 持续更新，故高层面对的环境是**非平稳**的。这正是你 chap07 论证的落点，本文的形式化恰好把这一点讲得很清楚。

### Theorem 1：内选项策略梯度定理

给定一组内选项策略对参数 θ 可微的马尔可夫选项，期望折扣回报对 θ 的梯度为：
```
Σ_{s,ω} μ_Ω(s,ω | s_0,ω_0) Σ_a [ ∂π_{ω,θ}(a|s) / ∂θ ] · Q_U(s,ω,a)
```

作者特别指出与伪奖励方法的本质区别：

> 该梯度描述了**选项内部策略的改变如何影响期望折扣回报（即真实的任务目标）**。相反，**子目标或伪奖励方法假定选项的目标仅仅是**……（达成某个人为指定的子目标）。

> ★★★★★ **这段对比对你有直接用途**：你的 7 个专家各自有**专属奖励函数**（跳跃专家关心跳跃高度、单腿平衡专家关心横滚稳定），本质上就是**伪奖励/子目标**方法。Option-Critic 的立场是"伪奖励是次优的，应该让整体回报直接驱动选项内部策略"。
>
> **你必须正面回应这个质疑。** 建议的回应逻辑（写进第 7 章）：
> "Option-Critic 指出，以伪奖励定义选项目标无法保证整体回报最优。该论断在选项集合同质、可在统一 MDP 内联合优化时成立。但当各技能需要不同的训练环境（专用地形）、不同的训练干预（后空翻的外力课程）与不同的优化范式（约束投影 vs 无约束 PPO）时，联合优化在工程上不可实现——因为无法在同一批采样中对部分样本施加任务专属的动力学干预。因此本文接受伪奖励带来的次优性，以换取异构技能集合的可训练性，并通过高层调度器在**决策层面**而非**参数层面**追求整体回报最优。"
>
> ★★★★★ 这个回应把"次优"从缺陷变成**明示的工程取舍**，且指出对方前提在你的设定下不成立。**这是第 7 章必须写的一段。**

### Theorem 2：终止梯度定理

优势函数 `A_Ω(s', ω) = Q_Ω(s', ω) − V_Ω(s')` 出现在终止梯度中。作者给出了一个**极漂亮的直觉解释**：

> 优势函数常在策略梯度方法中作为基线出现以降低梯度估计方差，在那种语境下它的出现主要与算法设计有关。**有趣的是，在我们的情形中它是推导的直接结果**，并赋予定理一个直观的解释：**当当前选项的价值低于所有选项的期望价值时，优势函数为负，从而驱动梯度校正向上，这就提高了终止的几率**。终止之后，智能体……（重新选择更好的选项）

> ★★★★ **这个机理可以直接启发你的切换判据设计**：若你想给调度器加一个"何时该切换"的显式信号，`A_Ω(s,ω) = Q_Ω(s,ω) − V_Ω(s)` 是一个**有理论依据的标量**——当前专家的价值低于全部专家的期望价值时，就该切换。
>
> **这比 Yu 2025 用 CMA-ES 搜索的标量距离阈值优雅得多**，且天然是状态相关的（不是固定阈值），可自动表达"地形、姿态与能量状态的复合条件"。
>
> ★★★★★ **强烈建议**：在你的 chap07 滞回切换小节，把切换判据写成基于优势函数的形式，并配合滞回带（即 `A_Ω < −δ` 才切换，避免抖动）。这样你的切换机制就同时有 Option-Critic 的理论依据 + 你自己的滞回工程处理，比纯启发式规则强得多。这可能是第 7 章一个实质的方法创新点。

### 算法与架构

- **双时间尺度框架**（Konda & Tsitsiklis 2000）：**价值在快时间尺度学习，内选项策略与终止函数在慢时间尺度更新**。
- Actor 部分：内选项策略、终止函数、选项间策略；Critic 部分：`Q_U` 与 `A_Ω`。
- **架构不规定 `π_Ω` 如何获得**——可用 SMDP 层的策略梯度、基于选项模型的规划器、或 TD 更新。
- 若 `π_Ω` 取贪心策略，其一步 off-policy 更新目标 `g_t^{(1)}` 恰好等于 Sutton/Precup/Singh 1999 的**intra-option Q-learning** 更新目标。

### ★★★ 选项退化问题与 ξ 正则化（对你最关键的一段）

> **终止梯度倾向于随时间收缩选项（shrink options）。**

即：联合学习会使选项越来越短，最终**退化为单步基元动作**，时间抽象完全丧失。作者的补救措施：

> 我们在终止梯度使用的优势函数上加一个 **ξ = 0.01** 的项……该项起到**正则化作用**，通过施加一个 **ξ-边距（ξ-margin）**……从而**拉长（stretching）**选项。

并注明（Harb 等的 deliberation cost 思路）提出过类似正则化器。此外还应用了 Mnih 等 2016 的正则化器——**惩罚低熵的内选项策略**（防止内选项策略过早确定化）。

> ★★★★★ **这是你「专家冻结」立场最有力的论据之一，务必写进第 7 章。**
>
> 论证写法建议：
> "Option-Critic 在选项内策略与终止函数联合学习的框架下，需引入终止正则化项（ξ-边距）与内选项策略的熵正则化，以阻止终止梯度将选项持续收缩至单步基元、从而丧失时间抽象 [Bacon 2017]。这一退化源于终止函数与内策略在同一目标下相互竞争：任何单步的即时收益都会促使选项提前终止。本文的专家冻结机制从结构上规避了该问题——各专家的行为时长由其任务定义与专属奖励在分训阶段确定，整合阶段不再受高层梯度侵蚀，因而无需额外的正则化项即可保持稳定的时间抽象。"
>
> **注意这个论点的强度**：它不是"我们更简单"，而是"对方需要人为超参（ξ=0.01）来对抗一个结构性退化倾向，我们不需要"。**超参数越少是可辩护的优点。**

## 🧪 实验

### 1. 四房间导航（four-rooms，tabular）

**实验设计极其巧妙，值得学习**：

- 目标初始位于**东侧门口**，初始状态在其余格子中均匀采样；
- **1000 回合后，目标突然移动到右下房间的随机位置**；
- 基元动作有 **1/3 概率失败**（随机转移到相邻空格）；
- γ = 0.99，到达目标 +1，其余为 0；
- 内选项策略用 **Boltzmann 分布**参数化，终止函数用 **sigmoid**；
- 选项间策略用 intra-option Q-learning 学习；
- 温度参数 0.001，**全部权重初始化为零**；
- 学习率：critic 0.01，内选项梯度与终止梯度均 0.001；选项上用 **ε-greedy，ε = 0.01**。

**对照**：SARSA(0)、AC-PG（基元 actor-critic）、OC 4 选项、OC 8 选项。

**目的**：评估**完全自主学到的**选项集合从环境突变中恢复的能力。作者强调 Sutton/Precup/Singh 1999 做过类似实验但**用的是预先指定的选项**，而本文的选项**没有任何先验规定**。

> ★★★★★ **这个"环境突变后恢复"的实验范式非常适合移植到你的第 8 章**：
> 在混合地形遍历中途**突然改变某个地形单元的参数**（如把低台阶换成高台阶、把桥面变窄），观察调度器能否重新选择合适的专家。
> - 对**你的方案**：专家已具备各类能力，调度器只需重新决策 → 预期**快速恢复**；
> - 对**单网络基线**：需重新学习 → 预期**恢复缓慢或失败**。
>
> 这是一个成本低、图好看、直击"为什么要分专家"的实验，**强烈建议加入第 8 章**。

### 2. Pinball（连续状态）

- 状态空间在球的位置与速度上连续；
- 折扣因子 0.99，回合上限 10000 步；
- 阻尼 0.995（有限步后有效停止球的运动）；
- 测试阶段选项上用 **ε-greedy, ε = 0.05**；
- 网络第四（密集）层输出概率分布。

### 3. Arcade Learning Environment（Atari）

- 超参：**内选项策略与终止梯度学习率 0.00025，critic 用 RMSProp**；
- 配置：**8 个选项，0.01 终止正则化，0.01 熵正则化，内选项策略梯度使用基线**；
- 结果：**在 Asterix、Seaquest、Zaxxon 上超过原始 DQN 架构**；
- **Seaquest 的 2 选项特化现象（图 9）**：两个选项分别特化为**上/下（up/down）**按键序列——即选项自动发现了"上浮/下潜"这一有意义的时间抽象，**且无需任何子目标先验规范**。Krishnamurthy 等 2016 也在该游戏中发现了类似结构。

> ★★★ **"选项自动特化为语义清晰的行为"这一现象对你有一个反向启示**：Option-Critic 需要**训练后再解释**选项学到了什么（作者花了整页画特化图）。而你的 7 个专家**语义预先定义、天然可解释**（就是滚动行走、跳跃、后空翻）。
>
> 这是一个应当明确写出的**工程优势**："本文的专家划分依据步态语义预先给定，因而每个专家的功能天然可解释、可单独验收与调试；而端到端学习的选项其语义需在训练后通过可视化分析推断，且不保证与工程上有意义的步态划分对齐。对于需要真机部署与安全验证的机器人系统，可解释性与可单独验收性具有实际价值。"

### 3. ★ 优势函数作为切换判据（本篇最有价值的可移植点）

Theorem 2 的推导表明 `A_Ω(s,ω) = Q_Ω(s,ω) − V_Ω(s)` 天然是"是否应终止当前选项"的信号。

**对你的具体建议**（可作为第 7 章方法创新）：
```
切换条件：A_Ω(s, ω_current) = Q_Ω(s, ω_current) − V_Ω(s) < −δ
其中 V_Ω(s) = Σ_ω π_Ω(ω|s) Q_Ω(s,ω)，δ 为滞回带宽度
```
- **优点一**：有理论依据（Option-Critic 的终止梯度直接给出该形式）；
- **优点二**：状态相关，自动表达地形/姿态/能量的复合条件——**直接回应你在 chap01 对 Yu 2025 "切换准则被简化为标量距离阈值、决策变量随技能数组合爆炸"的批评**；
- **优点三**：δ 只有一个超参，且物理含义清晰（切换的价值裕度门槛）；
- **优点四**：与你已有的滞回机制天然融合。

> ★★★★★ **这是本篇对你最大的贡献**。它把你第 7 章的切换机制从"启发式规则 + 滞回"升级为"**基于价值裕度的切换判据 + 滞回带**"，理论依据来自 AAAI 经典，同时又与 Option-Critic 有明确区别（你不学 β_ω，而是由调度器的 Q 值直接导出）。建议在 chap07 单独写一个小节。

### 4. 双时间尺度：对你的联合微调阶段有直接指导

Option-Critic 用双时间尺度：**价值快、策略慢**。

## 💭 思考与延伸

**这篇论文对你的价值是"最强的对照面"。** 它代表了分层 RL 最正统的立场：一切都应端到端学习，人为规定的子目标是次优的。你的方案在这个立场下会被判为"倒退"——预先划分技能、用伪奖励、冻结低层。

**因此你的辩护必须建立在"约束"而非"偏好"上。** 具体说：

- 不要说"我们认为分训更好"（这是偏好，对方有理论支持）；
- 要说"**在异构算法范式与任务专属训练干预的约束下，联合优化在工程上不可实现**"（这是约束，对方的理论前提不成立）。

**最硬的一条**：后空翻需要 EFGCL 的外部辅助力课程（Yoneda 2026），即**修改环境动力学本身**。在联合学习框架内，你无法对同一批采样中的部分样本施加不同的动力学——因为价值函数会拟合到混合动力学上，给出错误估计。**这是数学层面的不可行，不是工程麻烦。** 这一条足以支撑你的全部立场。

**另一个值得深思的对称性**：Option-Critic 的终止梯度会让选项**过短**（退化为基元），而你的固定专家可能让选项**过长**（该切换时不切换，因为调度器的探索不足）。**两种失效模式恰好相反。** 你应当主动检查后者：统计各专家的平均持续时长，若某专家一旦激活就长期占据（如滚动行走专家在台阶前不肯交出控制权），就是"选项过长"的证据。**这个统计量应作为第 7 章的一项诊断指标**，且它与 Option-Critic 的问题形成漂亮的对称叙述——**这种"承认自己的对偶失效模式"的写法会显著提升论文的可信度**。
