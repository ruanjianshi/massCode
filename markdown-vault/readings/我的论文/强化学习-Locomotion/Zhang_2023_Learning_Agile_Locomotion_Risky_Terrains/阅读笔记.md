# Zhang 2024｜风险地形上的敏捷运动学习（ETH，梅花桩与独木桥）

## 📋 基本信息

- **作者:** Chong Zhang, Nikita Rudin, David Hoeller, Marco Hutter（**全部 ETH RSL**，Rudin 即 `rudin2022` 大规模并行仿真的作者）
- **平台:** **ANYmal-D** 四足，约 **50 kg**
- **仿真:** Isaac Gym；实机状态估计使用**动捕系统**（作者说明也可改用板载状态估计）
- **文章类型:** IROS 2024（arXiv 首发 2023-11）
- **成绩:** 稀疏梅花桩上峰值前进速度 **≥ 2.5 m/s**，窄独木桥上 **2.5 m/s**

## 🎯 研究目标

证明**端到端强化学习**也能在**稀疏落脚点的高风险地形**（梅花桩、独木桥、带间隙的桥）上实现**动态**运动——此前这类任务几乎都是模型驱动方法的地盘。

作者一上来就点明现有工作的两类困境：
- **模型驱动方法** [1]–[6]：仿真或实验室条件下表现好，但因**模型失配与意外滑移**在野外难以部署，且需要专门设计（运动参考 [9]、地形粗糙度与位姿安全等手工启发式 [3]）；肢体动力学必须简化 [2][4]；重规划因计算负担而缓慢 [3][5]。
- **RL + 模型驱动混合方法** [16][17]：用 RL 生成期望足端位置或机身加速度，再由全身控制器跟踪——**敏捷性受限，速度 ≤ 0.5 m/s**。文献 [18] 用 RL 跟踪模型规划器轨迹，性能出色，但**运动被规划器束缚且无法从失败中恢复**。

> ★★★ **这段相关工作对你第 1 章极有用**：它给出了"RL 与模型驱动混合"路线的**量化上界（0.5 m/s）**，而纯端到端 RL 达到 2.5 m/s。这是"为什么不用模型驱动兜底"的有力论据。

## 💡 核心贡献

1. 将文献 [20] 的**导航式任务表述**扩展到高风险地形；
2. 一套**探索策略**：改进课程 + 好奇心内在奖励 + 对称性数据增广；
3. **通才-专才两阶段训练**方法论（generalist → finetune specialists）；
4. 敏捷运动的成功 **sim-to-real** 迁移。

## 🔧 方法

### ★ 关键一：把运动表述为导航任务，而非速度跟踪

**这是本文最重要的设计决策。** 作者的论证：

> 在这些地形上，机器人需要**快速调整自身速度**。速度跟踪表述（如 [19][12] 所用）**无法完成这些挑战性任务**，因为在梅花桩上给机器人指派"合适的速度指令"是**不可行的（intractable）**——不恰当的速度指令会起误导作用。

于是改为给**位置指令 p_t^c 与航向指令 ψ_t^c**，任务奖励为
```
r_task = (1/T_r) · 1/(1 + ‖χ_t − χ_t^c‖)     （仅在回合末段 T_r 时长内给出）
```
其中 χ 为位置/航向状态，`T_r` 定义奖励的持续时长。**这样策略就可以自由调制运动**——想走多快、用什么步态、要不要停顿，全由策略自己决定。

**代价**：奖励变得**极其稀疏**（只在回合末段才给），探索难度陡增。故需要下面的探索策略。

### ★ 关键二：三件套探索策略

**(1) 改进的课程设计。** 常规 Isaac Gym 课程做法是：表现好则升难度级，表现差则降级，在最高级表现好则随机分配难度级。作者发现在风险地形上这个课程会失效：

> 由于地形高度挑战且各难度级之间存在**难度断层（difficulty gaps）**，课程受稀疏奖励困扰。在某一级表现良好的策略在更高一级可能表现极差，导致**巨大的回报差异**，而**难度无关（difficulty-agnostic）的优化器会错误归因**这一差异。

改进方案：**放宽课程**——若策略在剩余时间内**无法超越随机动作的表现**，就让它**留在同一难度级持续交互直到攻克它**。

> ★★★★ 这个"错误归因"的机理分析对你第 3 章有用：它说明**难度无关的优化器无法区分"策略变差"与"任务变难"**。这是课程学习与灾难性遗忘交叉处的一个精细问题。

**(2) 好奇心内在奖励（curiosity-driven intrinsic reward）。** 采用 RND（Random Network Distillation）[21] 的一个简化版本 [30]：
```
r_curio(s, a) = c_curio · |M₁(s, a) − M₂(s, a)|
```
`M₁`、`M₂` 是两个**随机初始化**的神经网络，输入为**状态-动作对 (s,a)**，其中 `M₁` 可被训练去拟合 `M₂`。对陌生的 (s,a) 对该奖励高，对熟悉的衰减至 0。

作者特别提到：好奇心奖励虽然主要用于探索，但**也能提升某些已学技能的鲁棒性**。

**(3) 对称性数据增广。** 利用机器人的**左右对称与前后对称**（来自 [22]），把增广后的状态-动作对赋以与原始对**相同的回报**，从而同时提升 actor 与 critic 的数据效率。

### ★ 关键三：通才-专才两阶段训练

作者发现：**即使有上述探索策略，也仍然无法在图 1 那些地形上从零学出专才策略。**

方案：
- **阶段一**：在相对简单的 `Stones-Everywhere`（杂乱稀疏梅花桩）上训练**一个通才策略**，学到可复用的基础运动技能；
- **阶段二**：从通才策略**微调**出各地形的**专才策略**。

**通才策略只需训练一次**，新地形只需数据高效的微调。

### 四类地形

| 地形 | 用途 | 参数 |
|:--|:--|:--|
| **Stones-Everywhere** | 通才训练 + 消融基准 | 石块尺寸 w_stone、石块间隙 w_gap、最大偏移量可调；实机测试时石块 **20 cm 宽、仅占总面积约 10%**，高低石块**高差 12 cm** |
| **Stones-2Rows** | 专才微调（含 sim-to-real） | 两行石块 + 3 个间隙，桥段 100 cm × 20 cm |
| **Balance-Beams** | 专才微调（含 sim-to-real） | 石块**从两行逐渐合并为一行**（随难度级演进），引导策略学习**猫步（catwalk）**式运动 |
| **Stepping-Beams** | 专才微调（仅仿真） | 宽度 [12, 17] cm，水平间距 [30, 60] cm，垂直间距 [0, 20] cm |

**Balance-Beams 的课程设计极其巧妙**：不是直接给一根窄梁，而是让两行石块**随难度递增逐渐合并**，从而把"宽支撑→窄支撑"做成连续过渡，避免策略卡在"只在宽梁上有效"的局部最优。

### 奖励设计

- **同一套奖励函数在仿真中对所有地形都能工作**，但为在真实世界获得"优雅的运动"，需**按地形微调权重**。
- 奖励项构成：
  - **位置跟踪 + 航向跟踪**（任务性能）
  - **提前终止惩罚 + 碰撞惩罚**
  - 正则化：关节速度、机身与足端加速度、动作变化率、力矩、接触力
  - 探索引导：`Don't wait`、`Move in Direction`（来自 [20]）
  - `Stand Still` 奖励（用于 Balance-Beams）
  - `Stand Pose` 奖励

### 领域随机化

- 用于提升鲁棒性与 sim-to-real
- **质心（CoM）被重度随机化**（尤其针对 Balance-Beams）

## 🧪 实验

### 消融（Stones-Everywhere，3 个随机种子，8000 迭代检查点，1000 试次 / 100 个随机地形）

对比设置：`w/o navigation`（改用速度跟踪）、`w/o curriculum`、`w/o curiosity`、`w/o augmentation`、`proposed`。

**指标一：通过 6 m 的成功率 vs 难度级**

- **在难度级 4（稀疏度约 40%）之后，速度跟踪表述的平均成功率低于 90%，并随难度快速崩塌**；
- 而所有基于导航表述的设置都能保持高成功率。
- 测试速度跟踪时用的是 **0.8 m/s 前进**（经验上最鲁棒的取值）——即已经给了最有利条件。

> ★★★★★ **这是你独木桥/木桩专家任务定义的决定性证据**：速度跟踪在稀疏度 >40% 时崩溃。

**指标二：最高难度级下通过不同距离的成功率**

- 所有技术都显著贡献鲁棒性，其中 **对称性数据增广最关键**；
- 改进课程与好奇心奖励效果相对较小；
- 对称性增广还使运动**更平衡、机身倾斜更少**。
- `w/o augmentation` 在**低难度地形上反而表现不好**，作者的解释极为重要：

> 无数据增广时策略无法攻克最难地形，**神经网络策略在机器人卡在高难度地形上时，遗忘了低难度地形上的样本**。

> ★★★★★ **这是灾难性遗忘在课程学习内部的直接观测**，且发生在**同一个任务的不同难度级之间**，比 He 2026 的跨步态遗忘**更细粒度**。可直接补入你第 3 章的证据链——说明遗忘不只发生在"不同技能"之间，连"同一技能的不同难度"都会遗忘。

### ★ 迁移矩阵（图 9）——本文对你最有价值的表格

矩阵值 = 能以 80% 成功率通过 3.5 m 的最高难度级（0~9，9 最难）；`<0` 表示在第 0 级成功率仅 [50%, 80%)。

| 训练地形 ↓ / 测试地形 → | Stones-Everywhere | Stones-2Rows | Balance-Beams | Stepping-Beams |
|:--|:--|:--|:--|:--|
| **Stones-Everywhere** | 9/9 | 6/9 | **<0/9** | 2/9 |
| **Stones-2Rows** | 9/9 | 9/9 | **3/9** | 6/9 |
| **Balance-Beams** | 3/9 | **<0/9** | 9/9 | **<0/9** |
| **Stepping-Beams** | 4/9 | 7/9 | **<0/9** | 9/9 |

作者的结论：

> 由于地形相似性，`Stones-Everywhere` 与 `Stones-2Rows` 上训练的策略可以**相互迁移**，后者也可与 `Stepping-Beams` 相互迁移。**对于其他地形对，策略迁移效果很差。** 这一结果说明，尽管这些策略**源自同一个通才策略**，它们仍因训练数据而**高度分化**。因此，若想得到一个在各类地形上都表现良好的统一策略，**必须随机化机器人可能遇到的所有地形**。

> ★★★★★ **这是你「按地形分专家 + 调度器」路线的最硬实证**。注意其逻辑链：
> 1. 专才策略即使同源，也会高度分化 → 单一策略无法覆盖异构地形；
> 2. 作者给出的补救办法是"随机化所有可能地形"——但这等价于**回到单网络多任务**，而 He 2026 与 Huang 2025 已证明该路线会遭遇梯度冲突与灾难性遗忘；
> 3. **你的方案正是跳出这个二难：保留分化的专才，用调度器在它们之间选择。**
>
> **务必把这个三段论写进第 3 章或第 7 章。** 它把 Zhang 的"局限"直接转化为你的"动机"，而且是 ETH 组自己的数据。
>
> 另注意 **Balance-Beams ↔ 其他地形几乎全部 `<0`**——独木桥是**最孤立**的技能。这正好支撑你把"单腿平衡/独木桥"设为**独立专家**且在调度上采用**硬切换**（而非软混合）的决策。

### 微调 vs 从零训练

| 策略 | 迭代数 |
|:--|:--|
| 通才（Stones-Everywhere） | 8000 |
| Stones-2Rows 专才（微调） | **2000** |
| Balance-Beams 专才（微调） | **3000** |
| Stepping-Beams 专才（微调） | **1000** |
| **从零训练（每任务）** | **10000 也学不出来** |

### 真机实验

| 地形 | 成功率 |
|:--|:--|
| Stones-2Rows | **8/10** |
| Balance-Beams | **5/5** |

- **梅花桩**（图 10）：机器人**频繁向上向前跃起**通过地形；
- **独木桥**（图 11）：机器人**先缓慢对准梁中心再落到梁上**，随后**快速交替左右对角腿**，并在 3~5 s 处**速度爆发**通过。
- **仿真行为**：在最难 Stones-Everywhere 上给一串航点即可实现全向运动，且**在不同情形下自发采用不同步态**——易找到安全落脚点时用 3 接触 walk 或 2 接触 trot，否则用 2 接触 pace。
- **失步恢复**（图 6）：足端受约 100 N 外力持续 0.4 s 导致踏空后，机器人**用腿压住石块把自己向上向前拉回**并继续行走。

## 🔗 与你当前工作的关联

### 1. 独木桥专家的任务表述必须改（最高优先级行动项）

你目前第 5 章单腿平衡/独木桥专家很可能仍沿用**速度跟踪**（与滚动行走专家一致）。本文数据表明：**稀疏度 >40% 后速度跟踪成功率跌破 90% 并快速崩塌**。

**建议**：独木桥与木桩两个专家改为**导航式表述**（给目标位置 + 航向），奖励用
```
r_task = (1/T_r) · 1/(1 + ‖χ_t − χ_t^c‖)
```
只在回合末段给出。这样策略可自主决定"先对准再爆发"这类分段策略——**而这恰好是真机上观测到的行为**。

⚠️ **但这带来一个架构问题**：如果独木桥专家的**指令语义**从"速度指令"变成"位置指令"，那么它与滚动行走专家的**指令空间也不同了**。这正好**加强**你在 chap07 提出的「统一动作接口层」的必要性——异构不仅在动作输出侧，**也在指令输入侧**。

> ★★★★★ 这是一个可以让你第 7 章更有说服力的新论点，建议补写。

### 2. 木桩地形的课程设计：借用"两行合并为一行"的连续过渡

你的独木桥地形若直接给固定宽度桥面，策略很可能卡在"只能在宽桥上走"的局部最优（本文明确提到这个局部最优）。**建议把桥宽做成课程变量，从双轮可并排的宽度连续收窄至单轮宽度**——这与你的"单腿平衡"目标天然契合：桥宽收窄到小于轮距时，策略被迫学会单腿支撑。

> ★★★★★ 这比直接训练单腿平衡再迁移到独木桥**更自然**，且给出了一条平滑的课程路径。可作为第 5 章的方法创新点之一（两轮足版的"支撑面连续收窄课程"）。

### 3. 好奇心内在奖励：你的后空翻可能不需要它，但独木桥可能需要

- 后空翻你已定了 EFGCL 外力课程（改动力学）；
- 独木桥/木桩是**稀疏奖励 + 大量失败方式**的典型场景，RND 式好奇心奖励（两个随机网络之差，实现极简）是低成本可试项。
- 注意本文消融显示好奇心奖励**效果相对较小**（对称性增广最关键），所以优先级排在增广之后。

### 4. 对称性数据增广：两轮足只有左右对称，没有前后对称

本文用了**左右 + 前后**两种对称性。你的两轮足：
- **左右对称**：成立（两条腿两个轮）→ **可用**，且本文证明这是**最关键**的技术；
- **前后对称**：两轮足前后不对称（机身有朝向），**不可用**。

**建议**：在 UniLab 中实现左右镜像增广——把观测中左右腿相关分量交换、y 向速度与 roll/yaw 取反，动作同样处理，赋相同回报。这对**单腿平衡**尤其有价值（左支撑与右支撑本质是同一技能的镜像，增广后样本量直接翻倍）。

> ★★★★★ 这是本篇性价比最高的可移植项：实现成本低（纯观测/动作索引重排），而本文消融证明它是**最关键**的一项。

## 💭 思考与延伸

**本文与你的关系是"同一问题的两种答案"。** Zhang 等承认专才策略高度分化，但他们的应对是"那就把所有地形都随机化，训一个大策略"——这是 ETH 组一贯的"scale up + randomize"风格。你的应对是"承认分化，显式管理分化"。

**关键在于：谁的路线在技能异构度更高时更成立？** Zhang 的四类地形本质上都是"四足在离散落脚点上行走"，**动作分布仍在同一族内**（都是步态，只是落脚约束不同），所以"随机化全部地形"是可行的。而你的技能集合包含**滚动行走与后空翻**——这不是同一族的变体。**因此 Zhang 路线在你的问题上不成立，而这不是因为方法差，是因为问题的异构度不同。** 这个论证要写得精确，不要泛泛说"我们的更好"。

另一个值得注意的细节：本文真机上独木桥成功率 **5/5**，而梅花桩 8/10。**更窄的地形反而成功率更高**——原因很可能是独木桥是"连续但窄"，而梅花桩是"离散且需精确落点"。这提示你：**独木桥对两轮足可能比木桩容易**（两轮足在桥上仍是连续滚动接触，而木桩要求腾空跨越）。**建议把木桩地形的难度评估上调**，训练资源与课程设计上给木桩更多投入。

最后，"先缓慢对准梁中心再速度爆发"这一自发涌现的分段行为，正是**导航式表述的直接产物**——若用速度跟踪，策略被迫全程维持指令速度，不可能自主决定"先慢后快"。这个例子非常适合放进你的第 5 章作为任务表述选择的定性说明。
