# Yoneda 2026｜EFGCL：体操保护式外力引导课程学习

## 📋 基本信息

- **作者:** Keita Yoneda（米田启太）、Kento Kawaharazuka、Kei Okada
- **单位:** 东京大学 信息理工学系研究科 机械信息学专攻（JSK 实验室）+ 东大 AI Center
- **平台:** **KLEIYN** —— 自研四足机器人（作者同组 IROS 2025 工作），**总质量 18 kg**、高 600 mm，单腿 3 DOF + **躯干 1 DOF（主动腰关节）**，共 13 关节
- **执行器:** 腿部准直驱（quasi-direct-drive），**峰值力矩 24.8 N·m**；躯干电机 **48 N·m**
- **传感:** IMU + 关节编码器（纯本体感知，无外感知）
- **仿真:** Isaac Gym
- **状态:** RA-L 2026 已接收；arXiv:2605.10063v1（2026-05-11），7 页
- **任务:** Jump（定高跳跃）、**Backflip（后空翻）**、Lateral-flip（侧空翻）

## 🎯 研究目标

解决**高风险、高动态全身动作**（跳跃、空翻）的强化学习探索难题：失败轨迹占绝对多数 → 价值函数把大量状态估得极低 → TD 误差 $\delta_t$ 与优势 $A_t$ 双双趋近于零 → **梯度里几乎没有有用信息 → 训练停滞**。

**核心主张（也是本文最重要的思想）**：不要通过改**奖励**（reward shaping）或喂**参考轨迹**（imitation）来引导，而是通过**改造 MDP 本身**来引导 —— 在训练早期直接给机器人施加物理上的「扶一把」，让它**亲身体验成功**，之后逐步撤掉。

> 这个洞察来自艺术体操的 **spotting（保护/助力）**：教练在运动员练新动作时用手托扶。本质是**物理引导**，而非**信息引导**。

## 💡 核心贡献（作者自述三点）

1. 提出一种**新的动态技能学习范式**：用外力做物理引导，而非用奖励设计做引导。
2. 提出 **EFGCL**：让辅助外力按课程逐步衰减，证明物理引导显著提升探索效率。
3. **真机验证**：三个任务全部成功迁移到实物四足机器人。

## 🔧 方法

### 1. 为什么标准 PPO 学不出空翻（理论动机，值得在大论文里引用）

$$\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t),\qquad \nabla_\theta J(\theta) \propto \mathbb{E}\big[\nabla_\theta \log \pi_\theta(a_t|s_t) A_t\big]$$

高风险环境中失败轨迹主导 → $V(s_t)$ 普遍很小 → $\delta_t \to 0$、$A_t \to 0$ → **梯度无信息**。

**反过来的机制（本文的立论基础）**：一旦观测到足够多的高回报轨迹 $\xi^{high}=\{s_t\}_{t=0}^N$，这些状态的 $V(s)$ 会被估得很高；此后任何偏离该轨迹的动作都会产生**大的负 TD 误差与负优势**，策略便被推向「不要偏离已获得的高回报轨迹」的方向 —— **好动作一旦学会就会被牢牢保住**。

> 所以问题的本质是：**能否在训练早期就让价值函数给近优行为打高分**。EFGCL 用外力人为「加密」成功轨迹的出现频率来做到这一点。

### 2. 课程学习为何与 PPO 天然契合（本文的另一个理论小贴士）

课程学习可解释为在一串风险递增的 MDP $\mathcal{M}_i$ 上顺序学习。若相邻阶段的动力学与奖励结构变化足够小，则

$$\frac{\pi^*_{i+1}(a_t|s_t)}{\pi^*_i(a_t|s_t)} \approx 1$$

这**恰好就是 PPO 假设的「小步更新更好」**。因此课程学习在理论上与 PPO 高度对齐 —— 这句话可以直接搬进你大论文第 3 章为「分训-整合」的阶段化设计做理论辩护。

### 3. EFGCL 算法（Alg. 1，完整可实现）

```
输入：初始策略 π_init、初始 critic V_init、辅助力 F_assist、衰减步长 ε、成功率阈值 ζ
F_0 ← F_assist，α ← 1.0
for i = 0 … N-1:
    success_rate ← 0
    while success_rate < ζ:                     # 成功率驱动的自适应课程
        用 PPO 在辅助力 F_i 下训练 π_i 和 V_i
        更新 success_rate
    α ← max(0, 1 - ε × i)                        # 线性衰减
    F_{i+1} ← α × F_assist
    π_{i+1} ← π_i,  V_{i+1} ← V_i                # 策略与价值函数跨阶段继承
return π_N
```

**关键设计点**：
- **成功率驱动**（而非固定迭代数驱动）的课程推进 → 自动保证 $\pi_{i+1}/\pi_i \approx 1$，防止难度阶跃
- **价值函数 $V$ 也跨阶段继承**（不只是策略）—— 这一点常被忽略，但正是「保住已学会的东西」的关键
- 本文超参：**ζ = 0.6，ε = 0.01**（三个任务全部相同，未做任务级调参）

### 4. 辅助力的定义与设计

辅助力被参数化为三元组：

$$F_{assist}(P, F, T),\quad P=\{p_i\}\ \text{作用点},\ F=\{f_i\}\ \text{力矢量},\ T=\{(t_i^{start}, t_i^{end})\}\ \text{作用时段}$$

**所有任务共用作用时段 $T=\{(1.0\,\text{s},\ 1.1\,\text{s})\}$**（即只施加 **0.1 s** 的冲量式辅助！），作用点与力矢量按任务设计，**全部竖直向上施加在肩胛（scapula）连杆上**：

| 任务 | 作用点 P | 力矢量 F |
|:---|:---|:---|
| Jump | 四条腿的 scapula（FL/FR/BL/BR） | $(0,0,f_{jump}(h^{target})/4)$ |
| **Backflip** | **前两腿 scapula（FL/FR）** | $(0,0,\mathbf{175\ N})$ |
| Lateral-flip | 右侧两腿 scapula（FR/BR） | $(0,0,\mathbf{300\ N})$ |

- Jump 的力幅值 $f_{jump}(h^{target})$ **由抛体运动模型解析算出**：把跳跃建模成抛体，反算达到目标高度所需初速度对应的平均辅助力
- **后空翻的物理直觉极其简洁**：只在**前半身**竖直上提 175 N，持续 0.1 s，自然产生绕 pitch 轴的**后仰角动量**。机器人 18 kg（重力约 176 N）—— 即 **175 N ≈ 1 倍自重**，只施加在前半身
- 侧空翻用 300 N（约 1.7 倍自重）施加在**右侧**两腿 → 绕 roll 轴翻滚

> 🔑 **这是全文最可移植的一点**：辅助力**不需要教最优轨迹**，只需要把机器人「大致推到」高回报状态即可。作者原话：*"the purpose of the assistance is not to teach an optimal trajectory but rather to guide the agent toward high-reward states"*。

### 5. 时间编码观测（Time-Encoding，小而关键的技巧）

由于辅助力是**时变**的，智能体必须能推断「辅助何时到来/何时消失」。但直接把流逝时间 $t$ 当输入会单调增长、量纲失配。作者设计了一个有界单调函数：

$$\tau(t,\lambda)=\frac{\tilde t^{\,3}}{1+\tilde t^{\,3}},\qquad \tilde t=\frac{t}{\lambda},\qquad \lambda = t^{start}$$

- 取 $\lambda$ = 辅助力起始时刻，则 $t=t^{start}$ 时 $\tau=0.5$，$\tau\in[0,1]$ 有界
- 三次方使得在 $t^{start}$ 附近变化最陡 → 在关键时刻分辨率最高

> 💡 **对你的价值**：这正是你 `backflip.py` 需要的「相位/进度」观测。比直接喂归一化时间 $t/T$ 更好（有界 + 关键时刻高分辨率），也比正弦相位更适合**单次性开环动作**（空翻不是周期运动，用不了步态时钟）。

### 6. 观测空间

**本体感知 $o_t^{prop}$**：关节位置 $q_t\in\mathbb{R}^{13}$、关节速度 $\dot q_t\in\mathbb{R}^{13}$、根系重力矢量 $\tilde g_t\in\mathbb{R}^3$、根系角速度 $\omega_t\in\mathbb{R}^3$、**指令 $c\in\mathbb{R}$（1 维！）**、**时间编码 $\tau(t)\in\mathbb{R}$**

- 指令只有 1 维：Jump 是目标高度 $h^{target}$，Backflip/Lateral-flip 是目标转角 $\theta^{target}$

**特权观测 $o_t^{priv}$**（仅教师策略可见，任务专属）：
- Jump：根高度 $h_t$ + **回合内历史最大高度 $h_t^{max}$**
- **Backflip：根高度 $h_t$ + 根 pitch 角 $\theta_t^{pitch}$**
- Lateral-flip：根高度 $h_t$ + 根 roll 角 $\theta_t^{roll}$

> 注意特权观测**极少**（只有 2 维），与 Chamorro 的高度网格 + 接触力那种「重特权」路线截然不同。因为难点在探索而非感知。

### 7. 奖励函数（**三任务完全共用**，Table I / II）

**这是本文最有说服力的实验设计**：为避免「性能来自任务专属奖励工程」的质疑，三个任务共用**完全相同的奖励结构、权重、函数形式**，只有目标变量不同。

$$r_t = \rho_t^{task} + \rho_t^{task}\cdot\rho_t^{stand} + \lambda_\omega r_t^{ang} + r_t^{common}$$

| 奖励项 | 定义 |
|:---|:---|
| 任务进度 $\rho_t^{task}$ | $\exp(-\lVert x_t - x^{target}\rVert^2 / s_x)$ |
| 站立稳定 $\rho_t^{stand}$ | $\exp(-\lVert h_t\rVert^2/0.01) + \exp(-\lVert q_t - q^{stand}\rVert^2/0.25)$ |
| 角度正则 $r_t^{ang}$ | $-\lVert(\omega_t^{non\text{-}target})^2\rVert$（抑制非目标轴转动） |
| 碰撞惩罚 | $-1.0 \times \sum_{i\in P_{col}} (f_{i,z} > 0.1)$ |
| **终止惩罚** | $\mathbf{-100} \times \delta_t^{term}$（躯干触地即终止） |
| 关节速度惩罚 | $-5\times10^{-4}\lVert\dot q_t\rVert^2$ |
| 关节加速度惩罚 | $-1\times10^{-7}\lVert\ddot q_t\rVert^2$ |

| 任务 | 目标变量 $x_t$ | 目标值 $x^{target}$ | 归一化系数 $s_x$ |
|:---|:---|:---|:---|
| Jump | $h_t^{max}$ | $h^{target}$ | 0.01 |
| **Backflip** | $\theta_t^{pitch}$ | $2\pi$ | $\pi^2$ |
| Lateral-flip | $\theta_t^{roll}$ | $2\pi$ | $\pi^2$ |

**两个精妙之处**：
1. **$\rho_t^{task}\cdot\rho_t^{stand}$ 的乘积项** —— 落地稳定奖励**被任务进度门控**：没转够角度，落得再稳也拿不到分。这从结构上避免了「为了稳定而不敢翻」的退化解，比手工调「翻转 vs 稳定」的权重比高明得多。
2. **碰撞集 $P_{col}$ 含 14 个连杆**：body、scapula、thigh、calf，**排除 foot**。与 MUJICA「只打大腿小腿」的思路一致。

### 8. 教师-学生蒸馏

- **教师**：吃 $o^{prop} + o^{priv}$（经 Privileged Encoder 得 $l_t^{priv}$），用 RL（PPO + EFGCL）训练
- **学生**：只吃 $o^{prop}$，用 Belief Encoder 推断 $l_t^{priv}$，Belief Decoder 重建 $o^{priv}$；损失 = **动作匹配损失 + 特权观测重建损失**
- **EFGCL 只用于教师训练阶段**

## 🧪 实验

### 1. 学习性能（Fig. 5，10 个随机种子）

| 任务 | w/ EFGCL | w/o EFGCL（纯 PPO） |
|:---|:---|:---|
| Jump | 稳定收敛，**快约 2 倍** | 奖励方差极大 |
| **Backflip** | **稳定收敛到高回报** | **几乎学不动，失败** |
| **Lateral-flip** | **稳定收敛到高回报** | **几乎学不动，失败** |

- 可视化（Fig. 6）：纯 PPO 常常收敛到**不自然的姿态**且达不到目标动作；EFGCL 学出自然、稳定的动态动作
- **真机部署（Fig. 8）**：三个任务全部在 KLEIYN 上复现出与仿真一致的动作。后空翻真机时序：T=0.0 → 1.2 s

### 2. 辅助力设计的鲁棒性消融（Fig. 9，后空翻任务）—— 本文最实用的一张图

对**作用点、幅值、时机**三要素做扫描：

| 变量 | 成功范围 | 失败情形 |
|:---|:---|:---|
| **作用点** | scapula（主实验）/ **thigh / calf 均可成功** | — |
| **力幅值** | **140–210 N 均可成功** | **100 N（辅助不足）**、**250 N（辅助过度）** |
| **作用时机** | 1.0–1.1 s（主实验，0.1 s 时长） | **1.0–1.05 s（时长过短，0.05 s）** |

**结论：不需要精细调参，只要辅助力「大致促成」目标动作即可。** 这是 EFGCL 相比奖励整形的核心优势 —— 奖励权重往往需要在数量级上反复试（对比 He 2026 的 +20 / −180）。

> ⚠️ 但也要看到：**成功窗口是 140–210 N（约 ±20%），并非任意宽**。且力幅值是与机器人质量（18 kg）强耦合的，移植到你的两轮足平台时需要按 **辅助力/自重 ≈ 1.0** 的比例重新标定，而不是直接抄 175 N。

### 3. Critic 价值估计加速验证（Fig. 10）—— 机理的直接证据

在 Jump 任务上，对同一条成功参考动作在不同训练阶段的价值估计做对比：

- **w/ EFGCL：仅 200 iterations 就收敛到接近最终价值函数的分布**
- **w/o EFGCL：需要 1000+ iterations 才达到可比精度，且方差更大**

**这条实验直接证实了本文的理论动机**：让智能体早期体验成功状态，能显著加速价值函数估计。

**这是你 `backflip.py` 的首选方法论，没有第二个候选比它更贴合。**

你的处境与本文完全一致：后空翻是**高风险、稀疏成功、失败轨迹压倒性主导**的单次性动态动作，标准 PPO 大概率原地不动。而本文用 10 个种子证明了纯 PPO 在后空翻上**根本学不出来**，同时给出了一个只需三个超参（$F_{assist}$、$\varepsilon$、$\zeta$）的解法。

**与你已建立的四层文献栈的关系** —— EFGCL 补上了缺失的「**探索层**」，且与 Deng 的 DS 构成两条**互补**路线：

```
Shin_2023 MOR      → 电机层：动作在真机上是否可执行
CTBC (Li_2026)     → 触发层：何时切换到抬腿/迈步（接触反射）
Deng_2025 DS       → 奖励层：稀疏奖励下怎么探索（改「奖励」）
Yoneda_2026 EFGCL  → 探索层：稀疏奖励下怎么探索（改「MDP/动力学」）  ← 新增
Hou_2026 FTSR      → 技能层：单个高难技能怎么分阶段做好
Li_2026 MUJICA     → 架构层：多技能怎么共存、切换、约束
```

**DS vs EFGCL 的路线对比（你要在大论文里讲清楚的一个技术选择）**：

| 维度 | Deng 2025 的 DS 动态奖励整形 | Yoneda 2026 的 EFGCL |
|:---|:---|:---|
| 干预对象 | **奖励函数**（时变系数 $DS=(a\cdot t/T)^k$） | **MDP 动力学**（外部辅助力） |
| 需要的先验 | 知道哪些奖励项该被抑制、$a$ 与 $k$ 怎么取 | 知道往哪个方向推一把（物理直觉） |
| 设计者偏置风险 | **高**（中间奖励可能排除掉最优动作序列） | **低**（不规定轨迹，只增加成功状态密度） |
| 调参敏感度 | 需要逐项调权重与时变曲线 | **140–210 N 宽容窗口，作用点可换** |
| 保留稀疏奖励？ | 否（本质是稠密化） | **是**（明确保持稀疏奖励） |
| 是否改变仿真环境 | 不需要 | **需要能施加外力（Isaac/MuJoCo 都支持）** |
| 空翻任务证据 | 用于跌倒恢复（准静态） | **直接在后空翻/侧空翻上验证，且有真机** |

**我的建议：`backflip.py` 优先用 EFGCL，DS 作为第二层叠加。** 理由：
1. EFGCL 在**后空翻这个具体任务**上有直接证据，DS 只在跌倒恢复（准静态）上验证过
2. EFGCL 保持稀疏奖励 → 你的奖励函数会**干净得多**，写论文时「奖励项少」本身就是卖点
3. 二者**不冲突**：可以先用 EFGCL 让机器人学会「能翻过去」，再用 DS 分段（你已认可的 [0,0.3]/[0.3,0.7]/[0.7,1.0] 三段方案）精修落地质量。EFGCL 管「翻得成」，DS 管「落得稳」

**它对你大论文的另一重意义**：本文的「课程学习 ≈ 一串风险递增的 MDP，且相邻 MDP 的最优策略比值 ≈ 1，与 PPO 的小步更新假设天然对齐」这一论证，是你「分训-整合」两阶段范式**最漂亮的理论辩护**。你的调度器训练阶段（专家冻结、只学调度）也可以套进同一框架来论证稳定性。

   - MuJoCo 中用 `data.xfrc_applied[body_id]` 施加，或在 UniLab 的 env step 里加一个 external force 钩子

   - 若你的机器人有明确的前后区分（两轮足是左右对称、前后不对称），后空翻的辅助力应加在**质心前方**以产生后仰 pitch 角动量
   - 参数起点：$\zeta=0.6$，$\varepsilon=0.01$，幅值扫描 $[0.8, 1.2]\times mg$
2. **时间编码 $\tau(t,\lambda)=\tilde t^3/(1+\tilde t^3)$**（★★★★★，立刻可用）
   - 单次性动作（后空翻、跳跃）的相位观测最佳形式，有界且在关键时刻分辨率最高
   - $\lambda$ 取辅助力起始时刻 / 起跳时刻
3. **任务进度 × 落地稳定的乘积型奖励**（★★★★★，结构性技巧）
   - $r = \rho^{task} + \rho^{task}\cdot\rho^{stand}$，让落地稳定被翻转进度门控
   - **这可以替代你 DS 方案中的一部分手工分段**，且更不易退化
4. **价值函数跨课程阶段继承**（★★★★☆）
   - 课程推进时不要只保留 actor，critic 也必须继承，否则每次难度变化都要重新学价值
5. **三任务共用同一套奖励**（★★★★☆，写论文时的实验设计）
   - 你的 7 个专家若能证明「至少某几个共用同一套奖励结构、只改目标量」，会极大增强说服力（对比 He 2026 逐任务调权重）
6. **碰撞集排除足端**（★★★☆☆）：body/scapula/thigh/calf 计碰撞，foot 不计。你的两轮足对应：**排除轮子**，只打大腿/小腿/机体

## 🎯 对后空翻计划（backflip.py）的直接启示

**建议的实现路线（三阶段）**：

**阶段 1：EFGCL 打通「能翻过去」**
- 奖励只用 5 项：任务进度（pitch 角 → $2\pi$）、$\rho^{task}\cdot\rho^{stand}$、非目标轴角速度正则、碰撞、终止
- 观测加时间编码 $\tau(t)$ + 1 维指令（目标转角）
- 辅助力：起跳时刻起 0.1 s，质心前方竖直向上 $\approx 1.0\times mg$
- 成功判据（照抄本文）：$|\theta_t - 2\pi| < 0.3 \ \wedge\ |h_t| < 0.1$
- $\zeta=0.6$，$\varepsilon=0.01$

**阶段 2：叠加 MOR 电机约束（Shin 2023）**
- 后空翻是全篇里力矩需求最极端的动作，纯 $\tau$ clip 一定不够
- $-V_{bus} \le (R/K_t)\tau + (1/K_v)\omega \le V_{bus}$，且注意 **II/IV 象限（制动/回馈）工作区更宽** —— 落地缓冲正是在制动象限，这是可以「多用」的余量
- 若不加约束，仿真里学出的策略在真机上会因反电动势撞上母线电压而力矩塌陷（MUJICA 报告 >90% 样本越界 + 真机电机故障）

**阶段 3：DS 分段精修落地**
- 沿用你已认可的分段：$t/T\in[0,0.3]$ 蓄力起跳（DS≈0，放开甩腿）→ $[0.3,0.7]$ 空中翻转 → $[0.7,1.0]$ 落地稳定（DS→1，姿态/力矩/加速度惩罚全上）
- 注意：有了 EFGCL 的乘积型奖励门控后，DS 的必要性可能下降，**建议先不加，做成消融的一项**

**与跌倒恢复共享技能指示器 ζ（MUJICA 路线）**：后空翻失败即倒地，跌倒恢复是后空翻的**天然兜底技能**。两者在你的调度器里应该是紧邻的一对。

**一个额外的想法（可能是创新点）**：本文的辅助力是**启发式手工设计**的（作者在 Limitations 里明确承认这是最大局限，并把「自动生成/优化辅助力」列为 future work）。你的两轮足有 **轮子** —— 轮子可以当**飞轮**用（你已从 Xiong 2020 得到这个思路）。那么一个自然的问题是：**能否用轮子的反作用力矩替代一部分外部辅助力？** 即把 EFGCL 的「外部虚拟力」逐步替换为「内部可实现的轮子角动量」。如果做通，这就是一个**从虚拟辅助到自身执行器的迁移课程**，比单纯衰减到零更有物理意义，也直接回应了本文的 future work。

## ❓ 待解答的问题

1. 辅助力是施加在**仿真刚体**上的虚拟力，衰减到 0 后策略要完全自力更生。作者没报告「衰减过程中是否出现性能回落」的曲线细节 —— 从 Fig. 7 看衰减系数与成功率是耦合的，但成功率在衰减过程中的波动幅度多大？
2. $\lambda_\omega$（角度正则权重）取值多少？正文未给。
3. 后空翻的 $\theta^{target}=2\pi$ 是**累积转角**（需要能积分出多圈），那 pitch 角是怎么 unwrap 的？直接用 IMU 的 pitch 会在 $\pm\pi$ 处跳变。这在真机上是个实际问题。
4. 真机上 EFGCL 的辅助力是**不施加**的（只在教师训练阶段用），所以真机成功完全依赖 sim-to-real。但论文没报告真机成功率（只有 Fig. 8 的成功案例快照）——这是它的一个报告缺陷。
5. 作用时机 $T=(1.0\,\text{s}, 1.1\,\text{s})$ 是**绝对时刻**，意味着回合开始后 1.0 s 必须已经进入起跳准备。这暗含了一个隐式的「动作时序模板」。若机器人自己想在 1.3 s 起跳，辅助力就成了干扰。**这是 EFGCL 隐藏的一个先验注入**，作者没有讨论。你实现时要注意让辅助力时刻与你的起跳相位定义一致。

## 💭 思考与延伸

**1. 本文最深刻的一点：把「引导」从信息层面搬到物理层面。**

Guided-RL 的传统两条路 —— 模仿学习（喂轨迹）与奖励整形（喂中间奖励）—— 都是在**信息层面**告诉智能体「该怎么做」，因此都不可避免地注入**设计者偏置**：参考轨迹限定了动作形态，中间奖励可能排除掉真正最优的动作序列（本文引用 [16] 明确批评了这一点，并建议「用稀疏奖励 + 在奖励之外做设计」）。EFGCL 走的是第三条路：**不告诉它怎么做，直接让它做成一次**。这在哲学上更接近人类学习运动技能的方式，也更不容易封顶。

对你的意义：你大论文里 7 个专家中有相当一部分（跳跃、后空翻）目前都依赖精细的奖励工程。若能把其中一两个改成「稀疏奖励 + EFGCL」，你的方法在**奖励设计复杂度**这个维度上会显著优于 He 2026（13 项加权奖励）和 MUJICA。**这甚至可以单独写成一个创新点：「面向异构技能的低奖励工程量训练范式」**。

**2. 「保住已学会的东西」这个机制，与你的灾难性遗忘论述是同一个硬币的两面。**

本文的核心机理是：一旦高回报轨迹被价值函数认可，偏离它就会产生大负优势，于是**策略被牢牢锁在该轨迹附近**。这是好事（技能被保住），但换个角度看，**这正是灾难性遗忘的成因** —— 单网络学第二个技能时，第一个技能的高价值轨迹会持续产生「不要偏离」的梯度，与新技能的梯度直接对抗。He 2026 的 Phase 1 曲线（学会抬腿就忘掉滚动）就是这个机制的实证。

**把这两篇放在一起，你就有了一个完整的因果链条**：价值函数的「轨迹锁定」效应 → 单技能学习的稳定器 → 多技能学习的梯度冲突源 → 因此必须解耦。这个论证链比单纯引用「gradient conflict」文献要深刻得多，**强烈建议写进第 3 章开头**。

**3. 它是「单技能做到极致」的范本，恰好补上你分训阶段的方法论空缺。**

你的「分训-整合」范式中，「整合」部分（调度器）已有 MUJICA/MoE-Loco 等参照，但「分训」部分 —— 单个高难技能怎么才能训出来 —— 此前只有 Hou 2026 的 FTSR 分阶段方案。EFGCL 提供了第二个、且更通用的答案。而且它证明了一件对你极其有利的事：**后空翻这类技能，标准 PPO + 共享奖励结构根本训不出来，必须有任务专属的训练干预（辅助力设计）**。

这直接支撑你的「算法异构度」辩护：**如果后空翻必须用 EFGCL（外力课程）而滚动行走完全不需要，那么这两个技能在训练流程层面就是不兼容的** —— 你不可能在一个联合反传的 MoE 里对某些样本施加辅助外力而对其他样本不施加（那会破坏 MDP 的一致性，让价值函数学到一个混合了两种动力学的错误估计）。**这是我目前能想到的、对「7 专家完全解耦」最硬的技术论据，比参数量、技能正交度都硬。建议把它作为第 3 章的第一条理由。**

**4. 一个批判：辅助力的「作用时机是绝对时刻」暴露了方法的边界。**

$T=(1.0\,\text{s},1.1\,\text{s})$ 意味着方法只适用于**回合结构固定的单次性动作**。对于「在行进中遇到台阶时后空翻」这种需要自主决定时机的场景，EFGCL 无法直接用（辅助力不知道该何时来）。作者在 Limitations 里承认了连续动作的困难，但没意识到这个「时机先验」问题。

**对你的启示**：这恰好说明为什么你需要 **CTBC 式的显式触发层**。EFGCL 训练出的后空翻专家是一个「给定起跳时刻后的开环动作生成器」，那么「何时起跳」就必须由外部决定 —— 交给调度器（全局）或触发规则（局部）。这进一步强化了你在第 7 章要做的两层划分。

**5. 关于「辅助力 → 轮子飞轮」的迁移课程（重申，我认为这是本文给你的最大机会）。**

本文 future work 明确写着：*"Developing automatic optimization or generation methods for assistive forces... is an important direction for future work."* 而你的平台恰好有一个**天然的内部角动量执行器（轮子）**。设计一个课程：早期用外部虚拟力提供翻转角动量 → 中期逐步把角动量需求转移到轮子的反作用力矩 → 后期完全靠轮子 + 腿部甩动。这不是简单的「衰减到零」，而是**「从不可实现的辅助迁移到可实现的执行器」**。如果能跑通，这在方法论上是对 EFGCL 的实质性扩展，且是**两轮足平台独有的**（四足没有飞轮）—— 很可能构成一篇独立的小论文。
