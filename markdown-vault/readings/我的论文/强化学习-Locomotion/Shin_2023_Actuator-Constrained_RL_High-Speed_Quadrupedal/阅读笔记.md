## 📋 基本信息

- **第一作者:** Young-Ha Shin（申英夏）
- **通讯作者:** Hae-Won Park（朴海元，IEEE Member）— KAIST 机械工程系人形机器人研究中心
- **平台:** **KAIST Hound**（自研 45 kg 高速四足，齿轮比经混合整数非线性优化，ICRA 2022）
- **仿真:** RaiSim（硬接触模型）
- **提交日期:** 2023-12-29
- **资助:** 韩国国防采购计划厅（DAPA）/ 国防发展局（ADD）挑战性未来国防技术研发项目
- **纪录:** 跑步机上 **6.5 m/s**，电机驱动腿式机器人最快（此前 MIT Cheetah 2 为 6.4 m/s；此前 RL 方法四足最快仅 5 m/s）

## 🎯 研究目标

**高速奔跑时电机被用到能力边界附近**，而仿真里的关节力矩上限是 URDF 里的**矩形常数框**，与真实 DC 电机的**梯形工作区**不符 → 仿真中采样到大量真机不可行的状态转移，策略上真机就崩。

目标：把执行器的**力矩-转速工作区（Motor Operating Region, MOR）**作为约束嵌入 RL 训练，既避免不可行状态转移，又榨出电机全部性能。

## 💡 核心贡献

1. **MOR 线性不等式约束** — 用电机规格书就能得到的力矩-转速可行域，在仿真中对违规力矩指令做**饱和裁剪**（clip），阻断真机不可行的状态转移。
2. **关节空间 ↔ 电机空间变换** — 针对 KAIST Hound 的**并联执行器构型**（HFE 与 KFE 一体、HFE 空心轴），用叠加原理推出减速器矩阵，把 URDF 的关节量换算到电机侧。
3. **步态奖励均衡力矩分配** — 发现电机功率会**偏向一侧**，导致单电机饱和成为性能瓶颈；用对称步态（对角腿同时触地）奖励把四腿力矩摊平。
4. **轻量化足端设计** — 小腿质量降到原来 **38.0%**，俯仰方向惯量降到 **37.4%**。
5. **关键观察**：MOR 约束还能**引导策略网络在采样阶段主动避开不可行区域**（不只是被动裁剪）。

## 🔧 方法

### MOR：电机工作区的物理来源

准静态假设下（忽略电流变化率 di/dt，等同于用测功机采静态点画 τ-ω 曲线）的 DC 电机方程：

```
V_applied = iR + L·di/dt + V_BackEMF ≈ iR + V_BackEMF = (R/K_t)·τ + (1/K_v)·ω
```

于是工作区表示为一对线性不等式（母线电压 V_bus 限制）：

```
−V_bus ≤ (R/K_t)·τ + (1/K_v)·ω ≤ V_bus
```

再叠加**峰值力矩 τ_peak** 的限制：铁芯电机因**磁通饱和**导致电流-力矩非线性，τ_peak 定义为「偏离线性度达 20%」处；注意 τ_peak **不是绝对上限，而是防止绕组过热烧毁的推荐值**。

两者交出**第一象限的梯形工作区**。四个象限的物理意义：

| 象限 | 状态 | 特点 |
|:---|:---|:---|
| I | 正向加速 | 受 V_bus 限制 |
| II | 正向制动 / **能量回馈** | 电机当发电机，反电动势叠加母线电压 → **工作区比 I/III 象限更宽** |
| III | 反向加速 | 受 V_bus 限制 |
| IV | 反向制动 / 能量回馈 | 同 II |

> 这一点很重要：**减速/制动阶段可用的力矩比加速阶段更大**。论文批评前人（Fig. 引用 [8]）只考虑第一象限，忽略了对动态动作至关重要的减速区。

### 关节空间 ↔ 电机空间（并联构型的坑）

URDF 用「子连杆相对地面运动 = 父连杆运动量」的串联约定，无法直接描述 KAIST Hound 的并联构型：HFE 空心轴设计，HFE 转动时 KFE 输入与地面无相对运动。用叠加原理得：

```
[ω_HFE,m; ω_KFE,m] = [[1/G_HFE, 0], [−1/(G_HFE·G_KFE), 1/G_KFE]]^{-1} · [ω_HFE,j; ω_KFE,j]
[τ_HFE,m; τ_KFE,m] = (同一矩阵)^{-T} · [τ_HFE,j; τ_KFE,j]
```

（KFE 齿轮箱：太阳轮输入、齿圈固定、行星轮输出；但 HFE 输出与 KFE 齿圈固连，故 HFE 每转一圈会带动 KFE 齿圈转 1/G_KFE，从太阳轮视角等价于 −1/G_KFE。）

### 力矩饱和流程（训练闭环，Fig.5）

```
策略输出目标关节位置 θ_ref
   → 关节 PD 控制器（K_p = 50 N·m/rad, K_d = 1.0 N·m·s/rad，期望关节速度取 0）
   → 关节力矩 τ_joint
   → 减速器矩阵变换 → 电机力矩 τ_motor、电机转速 ω_motor
   → 若违反 MOR，裁剪到 MOR 边界
   → 反变换回关节空间 τ̄_joint → 施加到机器人
```

**真机侧的额外补偿**：仿真里低层指令是力矩，真机上是电流。铁芯电机在高力矩区电流-力矩非线性明显，故采集单轴电机的电流-力矩数据，用**二次近似**补偿网络输出的力矩 → 电流。

### 奖励函数（Table I，基于 Ji 2022 concurrent training 框架）

新增项加粗，其余沿用：

| 奖励 | 表达式要点 | 系数 |
|:---|:---|:---:|
| 线速度跟踪 | C_V·exp(−‖V_xy^des − V_xy‖²) | 6.0 |
| 角速度跟踪 | C_θ̇·exp(−1.5(θ̇_z^des − θ̇_z)²) | 3.0 |
| **接触速度** | C_contact·k_contact·‖V_f,z,i‖²（k_contact 仅在触地前一步为 1） | −6.0 |
| 足端滑移 | C_slip·C_f,i·‖V_f,xy,i‖² | −0.16 |
| 足端离地间隙 | C_clearance·(¬C_f,i)(z 误差)²·‖V_f,xy,i‖^0.5 | — |
| 姿态 | C_ori·angle(φ_body,z, φ_world,z)² | −3.0 |

| 关节速度 | C_q̇·‖q̇_t‖² | −3e-4 |
| 关节加速度 | C_q̈·‖q̇_t − q̇_{t−1}‖² | −0.67e-2 |

- **接触速度奖励**用来降低触地前足端相对地面速度，防止硬接触模型（RaiSim）里没体现的恢复系数导致真机接触不稳。
- **步态奖励**是解决单电机饱和瓶颈的关键（消融里少了它最高速掉到 6.0 m/s）。

### 网络与高速训练策略

- 策略网 / 值网 [256,128,64]，估计器网 [256,128]；估计器输出**机身线速度、足端高度、接触概率**，与原始观测拼接后送 actor（沿用 Ji 2022）。
- 控制频率 **100 Hz**，训练约 **6 小时**（Threadripper PRO 5995WX + RTX 3080 Ti）。
- **随机化**：机身质量、惯量、质心位置。
- **速度课程**：前向速度指令从 U(−0.3, 1.5) m/s 逐步放宽到 **U(−1.4, 7.0) m/s**。
- **回合初始状态技巧**：25% 概率用上一回合末状态作为本回合初值（学急加/急减速）；剩余 75% 从静止起，指令在第 1 秒内渐增（否则速度差太大时机器人会**干脆站住不动以免终止回合**）；那 25% 还限制两回合间指令差 ≤ 2 m/s。
- **奖励权重退火**：速度越高，力矩/关节速度等负系数项惩罚越大，机器人会倾向放弃跟踪 → 因此**逐步提高线速度与角速度奖励权重**。

### 轻量化足端

- 高速跑只需覆盖「与平地的攻角~离地角」范围的球面片段，不必做完整球/圆柱 → 由仿真跑步数据设计**最小球面片**足端。
- 结果：小腿质量 → 原来的 **38.0%**，俯仰惯量 → **37.4%**。

## 🧪 实验

### 仿真：MOR 违规带来的性能损失

- 不加 MOR 训练的策略，高速时严重越界；用 MOR 评估时，**从 4 m/s 起出现性能下降**（3 m/s 以下力矩本就在 MOR 内，无损失）。
- 剔除接触相关奖励（真机上接触概率估计噪声大）后趋势一致，说明该结论在真机上同样成立。

### 真机消融（跑步机，每档保持 10 s 算成功，0.5 m/s 递增）

| 配置 | 最高速度 |
|:---|:---:|
| 无步态奖励 | 6.0 m/s |
| 无定制轻量足端 | 5.5 m/s |
| **无 MOR 约束** | **4.5 m/s** |
| **本文完整方法** | **6.5 m/s** |

- 7 m/s 时机器人被跑步机推向后方、足端跑出带面，判定失败。
- **MOR 约束是三个因素里最关键的**（去掉后掉 2 m/s）。

### sim-to-real 差距

定义 Δreward_sim−to−real = 仿真评估 − 真机评估（剔除接触相关项）。两个策略在仿真里都能到 6.5 m/s：

- **有 MOR 约束**：3.5 m/s 之后 Δ **不再增长**。
- **无 MOR 约束**：Δ 持续增长，**真机在 5 m/s 时摔倒**。

### 顶速分析（6.5 m/s）

- 一个步态周期 **0.25 s**；触地 0.016 s、离地 0.089 s。
- **CoT（含机械功率 + 焦耳热）= 0.29**（15 步平均）。
- 真机与仿真的 τ-ω 轨迹高度吻合；KFE 在**支撑相早期出现负功能量回馈**，其 τ-ω 轨迹恰好沿着**第二象限**的 MOR 边界斜率走 —— 实证了「II 象限工作区更宽」的理论分析。

### 户外实验（正式聚氨酯田径场）

- 从 1.2 m/s 起步，6.7 s 内加速到 **5.9 m/s**；**100 m 用时 19.87 s**；**9 次全部完成、无一摔倒**。
- 比跑步机上的 6.5 m/s 略低，推测是**聚氨酯跑道偏软**所致。

### 讨论：MOR 为什么能「引导」而非仅「裁剪」

- 违规力矩被裁剪后，**力矩惩罚项的负奖励是一样的**（施加到机器人的力矩相同）；
- 但产生越界力矩指令所需的**动作突变会被动作平滑奖励重罚** → 于是策略学会主动避开不可行区。
- 训练过程统计（400 并行环境 × 4 s 回合 × 100 Hz = 每 iteration 160,000 个样本）：低速阶段违规率近零，指令升高后违规率上升，但**有 MOR 约束时收敛到明显更低的违规比例**。
- 附注：**不加动作平滑奖励训出的控制器在真机上会震动**。

## 🚀 可直接移植到 UniLab 的清单

1. **实现 MOR 裁剪（最高优先，改动小、收益大）**
   查你电机的 R、K_t、K_v、V_bus、τ_peak（规格书就有），在 PD 算出 τ_joint 之后、施加到仿真之前插一层：
   ```
   τ_motor, ω_motor = gearbox_transform(τ_joint, q̇_joint)
   τ_motor = clip_to_MOR(τ_motor, ω_motor)   # 含 I~IV 四象限，II/IV 更宽
   τ_joint = inverse_gearbox(τ_motor)
   ```
2. **四象限都要建模，别只做第一象限**。落地缓冲、空翻减速都在 II/IV 象限，那里可用力矩更大——只做第一象限会白白丢掉制动能力。
3. **电流-力矩二次补偿**：真机部署时把网络的力矩指令按实测 τ-i 曲线二次拟合转成电流指令，高力矩区偏差最大。
4. **动作平滑奖励必须留着**（一阶 + 二阶差分两项）。它是 MOR 「引导」效应的载体，也是真机不震动的前提。
5. **力矩均衡的步态奖励**：你两轮腿是左右两条腿，可设计「左右力矩差惩罚」防单侧膝电机先饱和。
6. **速度/难度课程 + 回合末状态复用**：25% 概率用上一回合末状态开局，学急加急减；剩余从静止起且指令第 1 秒内渐增（避免机器人「站住不动混完回合」这个坑——你的 jump/stairs 训练里可能也有）。
7. **奖励权重退火**：动作越激烈，力矩/速度惩罚越大导致策略放弃任务；对应做法是**随课程逐步提高任务奖励权重**。
8. **轻量化足端思路**：不必做完整球/圆柱，按实际攻角-离地角范围裁最小球面片。你的两轮腿是轮子接地，此条改为「减小小腿末端惯量」同样成立。

## 🎯 对后空翻计划的直接启示

1. **无 MOR 的后空翻是假的**。本文数据：不加 MOR 时真机最高速从 6.5 掉到 4.5 m/s，且 5 m/s 直接摔倒；MUJICA 那边是 >90% 样本越界、真机触发电机故障。两篇独立工作指向同一结论。
2. **落地缓冲要用 II/IV 象限的宽工作区**。后空翻落地是典型的负功/能量回馈工况，正好是电机能力最强的区域——建模对了，落地缓冲能力会比你预期更强。
3. **蓄力起跳要防单关节饱和**。空翻起跳时膝关节最易先饱和，参考本文步态奖励的思路，加「髋-膝力矩均衡」奖励把负载摊开。
4. **回合末状态复用可用于连续空翻**：25% 概率从上一回合末状态开始，天然适配「落地后立刻再翻一次」的连续动作训练。
5. **动作平滑 + MOR 是一对**：单靠 MOR 裁剪不会改变力矩惩罚，是动作平滑奖励让策略「不敢」输出越界指令。两者缺一，MOR 就退化成纯被动裁剪。

## ❓ 待解答的问题

1. 论文用的是**仿真内饱和裁剪**，MUJICA 用的是 **P3O 显式不等式约束**（本文结论也把它列为 future work，引 Kim 2023「不只有奖励还有约束」）。对后空翻这种极端工况，哪种更好？可能需要两者并用：裁剪保安全 + 约束项塑形。
2. τ_peak 取「偏离线性度 20%」是推荐值而非硬上限，后空翻这种瞬时动作能否短时超过？超多久会烧绕组？（涉及热模型，本文未建模温升）
3. 本文未建模**温度累积**与**母线电压随电池 SOC 下降**。连续多次空翻时 V_bus 会掉，MOR 会缩小——需要动态 V_bus。
4. 两轮腿的轮电机是**速度控制**模式，MOR 裁剪如何作用在速度指令上？（需要先由速度环反推力矩）
5. KAIST Hound 的并联 HFE/KFE 变换矩阵是该平台特有，你的 xqrobotwl 若是串联构型可直接用 URDF 的对角减速比，需确认。

```
Deng_2025 DS         →  奖励层：稀疏奖励下怎么探索出动作
Hou_2026 FTSR        →  技能层：单个高难技能怎么分阶段做好
Li_2026 MUJICA       →  架构层：多技能怎么共存、切换、约束
                            ↓
                    backflip.py on xqrobotwl
```

**最有价值的三句话**：
- 「URDF 的矩形力矩上限 ≠ 真实电机的梯形工作区」——这是几乎所有腿式 RL 工作默认踩的坑。
- 「II/IV 象限（制动/回馈）的工作区比 I/III 更宽」——只做第一象限会白丢制动能力，而制动正是落地缓冲的核心。
- 「MOR 约束不只是裁剪，它通过动作平滑惩罚引导网络主动避开不可行区」——机制上的洞察，比结果更值钱。
