## 核心贡献

1. **首次将约束强化学习 (Constrained RL) 应用于点足双足机器人**：采用 CaT (Constraints as Terminations) 框架 + PPO 训练 Bolt 机器人的 locomotion policy
2. **完整的开源 pipeline**：训练、推理、日志记录全部开源，基于低成本的 Bolt 机器人（ODRI 项目）
3. **实机验证**：在真实 Bolt 机器人上评估平衡保持、速度控制、推/滑扰动响应

## 方法概要

### 问题定义
- Constrained MDP: 最大化累计奖励的同时，确保约束违反概率 ≤ εᵢ
- CaT 框架：将物理约束（关节限位、力矩限制等）作为 episode termination 条件，违反即终止

### 状态与动作空间
- **状态**: 指令速度 (v*, ω*)、基座角速度 ω、投影重力、关节位置 q、关节速度 q̇、上一时刻动作
- **动作**: 6维 → 各关节角度位置指令（delta 动作 + 参考姿态 → PD 控制器跟踪）

### 奖励设计
- 线速度跟踪奖励: exp(-||v* - v||²)
- 偏航角速度跟踪奖励
- **约束**: 关节位置、关节速度、力矩等限制作为 termination 条件

### Sim-to-Real 策略
- Domain Randomization: 电机增益、摩擦系数等参数随机化
- CaT: 约束作为终止条件

## Bolt 机器人硬件特点

| 特性 | 说明 |
|------|------|
| 类型 | 点足双足机器人（无臂） |
| 自由度 | 每条腿 3 个力矩控制关节 |
| 来源 | ODRI (Open Dynamic Robot Initiative) |
| 特点 | 开源、低成本、3D 打印零件 |
| 足端 | 点接触（Point Feet）— 无平坦支撑面 |
| 控制 | 外部计算 + 以太网实时通信 |

### 关键挑战
1. **稳定性差**：点足无平坦接触面，支撑多边形极小
2. **无角动量调节**：无手臂，无法通过上肢抵消动量
3. **偏航控制受限**：无主动偏航机构
4. **运动学冗余低**：每条腿仅 3 个 actuator

## 实验结果

### 速度跟踪
- 稳定跟踪 x/y 方向速度指令
- 最大稳定行走速度：约 0.5 m/s
- 速度跟踪误差随速度增加而增大

### 抗扰动能力
- **推力恢复**: 接受来自各个方向的推力和脉冲扰动（实验结果用 impulse = %体重×秒 量化）
- **滑移恢复**: 地毯被拉走后机器人能保持平衡（实机演示）

### 能量效率
- 采用 Cost of Transport (CoT) 评估
- 不同速度下 CoT 变化趋势（论文图 3）

### 地面反作用力 (GRF)
- 分析了不同步态的 GRF 分布
- 验证了物理约束的合理性

## 个人思考

- 🔥 这篇论文对 **轮腿机器人** 的研究很有参考价值：轮腿机器人同样面临点足/小足接触的稳定性问题
- 无臂点足双足 = 更接近人类行走的动力学挑战
- CaT 框架的简单性（约束即终止）看起来很有效，代码也开源了，值得尝试复现
- 可以对比 ECO (能量约束优化) 的思路：两者都是约束 RL，但角度不同（能量 vs 物理约束）
