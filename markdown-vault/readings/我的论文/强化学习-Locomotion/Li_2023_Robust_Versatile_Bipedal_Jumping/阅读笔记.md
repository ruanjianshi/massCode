## 🎯 研究目标

使力矩控制双足机器人 Cassie 能够执行**多种一次性（非周期性）动态跳跃**，包括跳向不同位置、方向和高度，并实现精准着陆控制。

### 核心挑战

1. **混合动力学系统** — 起跳、飞行、落地三个阶段动力学截然不同
2. **欠驱动飞行阶段** — 腾空后无法通过地面反作用力控制姿态
3. **落地冲击大** — 需要吸收冲击同时保持站立
4. **时间窗口极短** — 全过程通常在 2 秒以内
5. **精准着陆要求** — 需要精确控制起跳时的线动量和角动量

### 此前状态

- 传统最优控制（OC）需要手工设计接触序列、简化模型，Cassie 上只能做固定跳跃（原地跳）
- 已有 RL 方法在 Cassie 上只能做**周期性跳跃（hopping）**，无法做**一次性的定点跳跃（jumping）**

## 💡 核心贡献

1. **首个系统**实现全尺寸力矩控制双足机器人（Cassie）执行多种动态跳跃，着陆位置可控
2. **Dual-History 策略架构**：同时利用长期+短期 I/O 历史，无需显式的 Teacher-Student 蒸馏
3. **三阶段训练框架**：单目标跳跃 → 多目标泛化 → 域随机化迁移，解决 sparse reward
4. **多目标训练提升鲁棒性**：通过训练多目标策略，机器人能在扰动后自动切换到其他已学跳跃动作来恢复
5. **零样本 Sim-to-Real**：仿真训练后直接部署到实物 Cassie，无需实物微调

## 🔧 方法

### 技术路线

端到端深度强化学习 + Dual-History 策略 + 三阶段训练 + Domain Randomization

### Dual-History 策略架构（核心创新）

- **短期 I/O 历史**：最近几帧的观测值 → 感知当前接触状态变化
- **长期 I/O 历史**：整个 episode 的观测序列编码 → 感知动力学偏移（如地面刚度变化）
- 两种历史通过不同时间尺度的 LSTM/MLP 编码，再拼接作为策略输入

相比 Teacher-Student 蒸馏方法，端到端双历史结构在动态任务上表现更好。

### 三阶段训练策略

| 阶段 | 内容 | 目标 |
|------|------|------|
| **Stage 1** | 单目标跳跃训练（原地跳） | 学习跳跃基本技能，从零开始模仿单次跳跃动画 |
| **Stage 2** | 多目标跳跃训练 | 学习跳到不同目标位置（距离、方向、高度），goal randomization |
| **Stage 3** | 动力学随机化 | 引入域随机化（质量、摩擦、地面刚度等），提升 Sim-to-Real 鲁棒性 |

### 奖励函数设计

奖励分两个阶段（t ≤ Tⱼ 起跳段，t > Tⱼ 落地后），加权求和 r(u,v) = exp(−α∥u−v∥²₂)：

**三类奖励项：** 参考运动跟踪（关节角度、骨盆高度、足端高度）+ 任务完成（着陆位置误差、速度跟踪、姿态偏差）+ 平滑项（地面冲击、力矩消耗、关节速度/加速度、动作变化率）

**特殊设计：**
- 参考运动 Tⱼ = 1.66s（跳跃动画时长），参考目标速度 = 目标距离/Tⱼ
- Stage 2/3 增加动作变化率奖励以平滑激进动作

### Episode 设计

- 每回合 2500 步（~76 秒），周期性 "站立→跳跃→站立→..."
- 跳跃目标采样：cᵪ∈(−0.5,1.5)m, cᵧ∈(−1.0,1.0)m, cz∈(−0.5,0.5)m, cϕ∈(−100°,100°)
- 若足端跟踪误差>0.32m 或落地距目标>0.35m/35°，提前终止

### 关键算法

- **RL 算法：** PPO
- **仿真平台：** MuJoCo
- **Sim-to-Real：** 零样本迁移（Stage 3 域随机化后直接部署）
- **策略架构：** Dual-History LSTM + MLP

## 🧪 实验结果

### 量化性能

| 指标 | 本方法 | 此前最优 (OC [71]) |
|------|:------:|:------------------:|
| 最大跳跃距离 | **1.4 m** (向前) | ~0.5 m |
| 反向跳跃 | **0.3 m** | 0 |
| 侧向跳跃 | **±0.3 m** | 0 |
| 空中转向 | **±55°** | 0 |
| 跳上高台 | **0.44 m** | 0 |
| 飞行时间 | **0.58 s** | 0.42 s |
| 顶点高度 | **0.47 m** (可控) | — |
| 着陆姿态控制 | ✅ | ❌ |

### 消融实验发现

1. **Dual-History > Short-only/Long-only**：双历史架构在所有指标上最优
2. **多目标训练提升鲁棒性**：能利用已学不同跳跃动作来恢复扰动
3. **Dual-History > Teacher-Student**：动态任务中更优
4. **无显式接触序列**：策略自动为不同目标学习不同接触模式

### 鲁棒性

- 落地冲击后可切换为另一次跳跃恢复
- 外部推力干扰下仍能完成任务
- **无需接触估计器**，隐式利用 I/O 历史推断接触状态

## ✅ 个人评价

### 优点
1. **成果硬核**：Cassie 上最丰富的双足跳跃技能
2. **架构简洁有效**：Dual-History 概念简单但非常有效
3. **分析透彻**：大量消融实验验证每个设计选择
4. **多目标训练的鲁棒性增益**：反直觉但很有价值

### 局限
1. 全部在仿真中训练，依赖仿真精度
2. 跳跃前需几秒站立预热
3. 落地后可能小跳几步（reward 设计允许）
4. 未涉及连续多跳或结合行走的复合技能

### 对研究的启示
- **Dual-History 架构**可借鉴到轮腿机器人跳跃
- **多阶段+多目标泛化**解决 sparse reward
- **自动发现接触序列**比手工指定灵活性更高
