# Combining SLIP Model and Reinforcement Learning for Agile Robotic Jumping

## 📋 基本信息

- **论文标题:** Combining SLIP Model and Reinforcement Learning for Agile Robotic Jumping
- **中文标题:** 结合 SLIP 模型与强化学习的敏捷机器人跳跃控制
- **作者:** Xiaowen Hu 等
- **发表年份:** 2026
- **发表 venue:** arXiv:2606.18625
- **研究方向:** 双足+四足机器人跳跃控制
- **关键词:** SLIP模型, 强化学习, 混合控制, Sim-to-Real

## 🎯 研究目标

结合 SLIP（弹簧倒立摆）模型的物理先验和 RL 的自适应能力，实现**高效、稳定、训练快**的机器人跳跃控制。

### 核心挑战

1. **纯RL训练慢** — 高维探索空间，需要大量数据
2. **纯模型方法适应性差** — SLIP 在非理想地形上性能退化
3. **Sim-to-Real 差距** — 仿真模型与实际机器人动力学不一致

### SRL混合架构

**物理模板（SLIP）提供前馈轨迹 → RL 做实时反馈修正**

## 💡 核心贡献

1. **SRL框架**：SLIP前馈 + RL反馈的混合控制器
2. **训练效率显著提升**：比纯 RL 基线训练时间大幅缩短
3. **多地形验证**：地面跳跃 + 楼梯跳跃，双足+四足仿真
4. **Sim-to-Sim 和 Sim-to-Real 验证**

## 🔧 方法

### SLIP模型

- 弹簧倒立摆模型，自然编码生物学启发的弹跳运动
- 提供前馈关节轨迹（基于能量约束）
- 在理想平坦地形表现优秀

### RL控制器

- 实时修正 SLIP 输出
- 适应不规则地形和外部干扰
- 学习鲁棒的反馈策略

### 混合架构

- SLIP 的输出作为 RL policy 的输入条件
- RL 输出残差修正项叠加到 SLIP 输出上
- 可端到端训练

## 🧪 实验结果

- 位置跟踪误差 < 0.1 m
- 速度跟踪误差 < ±3% 目标值
- 训练时间远少于纯 RL 基线
- 地面跳跃和楼梯跳跃均有效
- Sim-to-Sim 和 Sim-to-Real 迁移成功

## ✅ 个人评价

### 优点
1. **物理先验+RL自适应** 的组合思路简洁高效
2. 训练时间大大缩短，实用性高
3. 同时验证双足和四足

### 局限
1. 跳跃的高度和距离指标未与 SOTA 详细对比
2. 物理实验范围有限
3. SLIP 模型假设限制了某些复杂跳跃

### 对研究的启示
- **SLIP+RL 混合**可直接应用到轮腿机器人跳跃
- 不用纯 RL 从头探索，用物理模型兜底
- 对**落地冲击吸收**等物理约束场景尤其有效
