# Multi-Gait Learning for Humanoid Robots Using Reinforcement Learning with Selective Adversarial Motion Prior

## 📋 基本信息

- **论文标题:** Multi-Gait Learning for Humanoid Robots Using Reinforcement Learning with Selective Adversarial Motion Prior
- **中文标题:** 基于选择性对抗运动先验的人形机器人多步态学习
- **作者:** Yuanye Wu, Keyi Wang, Linqi Ye, Boyang Xing
- **发表年份:** 2026
- **发表 venue:** arXiv:2604.19102
- **研究方向:** 人形机器人多步态学习
- **机器人:** 12-DoF 物理人形机器人

## 🎯 研究目标

在单一策略中学习多种步态（行走、奔跑、跳跃），并实现零样本 Sim-to-Real 迁移。

### 核心挑战

- 不同步态（周期性行走 vs 一次性跳跃）的动力学本质不同
- AMP 约束对高度动态的跳跃步态可能适得其反
- 单一网络同时承载多种步态

## 💡 核心贡献

1. **选择性 AMP（Selective Adversarial Motion Prior）**：对周期性/稳定性步态用 AMP 约束，对高度动态步态省略 AMP
2. **多步态联合训练**：PPO + 域随机化
3. **零样本 Sim-to-Real 迁移**验证

## 🔧 方法

### 选择性 AMP 策略

- **行走/站立** → 使用 AMP 约束，生成自然的周期性运动
- **跑步/跳跃** → 省略 AMP 约束，让策略自由探索高动态动作
- 避免 AMP 对非常规动作的约束导致性能下降

### 训练框架

- PPO 算法 + 域随机化
- 单一策略网络
- 12-DoF 物理人形机器人

## ✅ 个人评价

### 优点
1. **选择性 AMP 设计简洁有力** — 不同步态不同约束策略
2. 对"跳跃"的处理方式值得参考：高动态步态应允许更多自由度

### 与你的大论文关联
- 你的"不同步态分别训练"思路与此一致
- 选择性 AMP 的"不同步态不同约束"思想可用在你的子策略设计中
- 为跳跃设计更宽松的奖励/约束

### 局限
1. 跳跃的高度、距离指标未给出详细数字
2. 实验侧重行走类步态，跳跃仅作为辅助
