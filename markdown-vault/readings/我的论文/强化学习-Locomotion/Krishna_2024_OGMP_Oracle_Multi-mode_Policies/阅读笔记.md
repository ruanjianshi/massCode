# Oracle Guided Multi-mode Policies for Agile and Versatile Robot Control

## 📋 基本信息

- **论文标题:** Oracle Guided Multi-mode Policies for Agile and Versatile Robot Control
- **中文标题:** Oracle引导的多模态策略用于敏捷多功能机器人控制
- **作者:** Lokesh Krishna 等
- **发表年份:** 2024
- **发表 venue:** arXiv:2403.04205
- **研究方向:** 双足机器人多模态控制（跑酷+跳水）
- **机器人:** HECTOR（16-DoF 动态双足机器人）

## 🎯 研究目标

提出通用多模态 RL 框架，使双足机器人能执行跑酷（跳跃、跨越、行走切换）和跳水（从不同高度跳下）等复杂任务。

### 核心挑战

1. 单一策略难以覆盖多种动态模式
2. 不同模式间的平滑切换
3. 无限长跑酷赛道需要持续生成新任务

### 解决方案

- 定义**Oracles**（任务先验，训练时提供状态参考）
- 在 Oracle 参考周围**bounding 状态空间**，引导探索
- 引入**task-vital modes**（跳跃、跨越、行走）和 **transition reward**

## 💡 核心贡献

1. **Oracle-guided policy optimization** — 任务无关的通用引导框架
2. **多模态定义** — 跳跃/跨越/行走作为独立 mode，transition reward 控制切换
3. **真实世界验证** — HECTOR 跑酷成功迁移到实物
4. **跳水任务** — 从最高 2m 高度全方位跳下

## 🔧 方法

### Oracle 引导

- Oracle 在训练时闭环比对生成参考状态
- bounding 策略输出在 Oracle 状态附近
- 训练后 Oracle 可以丢弃

### 多模态设计

- 每个 mode（跳跃/跨越/行走）有独立的策略头
- transition reward 鼓励不同 mode 之间的切换
- 在跑酷赛道中自动学习何时切换模式

### 实验结果

- 跨越间隙 **105% 腿长**
- 跳跃障碍 **20% 身高**
- 行走速度 **0.6 m/s**
- 模拟跳水 2m 全方位
- Sim-to-Real 跑酷成功迁移

## ✅ 个人评价

### 优点
1. **mode-based 架构设计清晰**，跳跃作为 mode 的思想直接适用你的课题
2. transition reward 机制简洁优雅
3. Oracle 引导有效降低探索难度
4. 真实机器人跑酷验证

### 与你的大论文关联
- **跳跃作为一个 mode**，与轮式行走做 transition reward 切换
- **自适应网络切换**可以借鉴 mode-based 多策略头架构
- Oracle 引导可用于训练每个子策略

### 局限
1. Oracle 在训练时需要提前设计
2. modes 数量固定，无法动态增加
