# Klemm 2020｜LQR 辅助的两轮足全身控制（Ascento）

## 📋 基本信息

- **第一作者:** Victor Klemm（vklemm@ethz.ch）
- **单位:** ETH Zürich，自主系统实验室（ASL）；Yvain de Viragh 属计算机系 CRL
- **平台:** **Ascento**——两轮足机器人，每腿一个**四连杆（four-bar linkage）**机构，共 4 个电机（2 个驱动轮 + 2 个驱动腿），膝部含**两个扭转弹簧**
- **计算平台:** Intel NUC7I7BNH，3.5 GHz 双核 i7（**注意：只是双核 mini PC**）
- **文章类型:** RA-L 正刊，8 页，2020 年 1 月录用
- **状态:** 有完整真机实验，非纯仿真

## 🎯 研究目标

为含**运动学闭环**的两轮足机器人推导**完整刚体动力学**，并在此之上综合一套**分层全身控制器（WBC）**，使 Ascento 从室内平地扩展到**户外不平地形**，同时解决两轮平衡机器人固有的**非最小相位（non-minimum phase）**动力学难题。

原有的 Ascento 控制器只是一个基于降阶模型的 LQR（即该组 2019 年 ICRA 的工作），在冲击扰动下**直接失稳倒地**。本文要用全身控制把「腿部主动柔顺」纳入平衡回路。

## 💡 核心贡献

- **两轮足完整刚体动力学推导，重点处理运动学闭环**（第 II-C 节）。作者明确对比了三条建模路线：
- 路线一：从**显式运动学**出发。对几何规则的连杆很容易，但当连杆长度不规则（**Ascento 正是这种**）时极为繁琐，且只适用于工作空间内**无运动学反转**的连杆机构；
- 路线二：纯**数值方法**（递归 Newton-Euler）。但它面向仿真，不便于导出解析运动方程；
- 路线三（**本文采用**）：**先在运动学上打开闭环，再通过求解合适的动力学约束力将其闭合**。理由是可得**闭式解**且能推广到非平凡系统。
- **基于旋转矩阵的紧凑闭式滚动约束表达**（第 II-D 节）。轮子接触点用轮廓参数 σ 与固定轮半径 ρ 参数化，接触系 C 的 z 轴沿当前**地面法向 n**、x 轴沿轮子航向，从而自然支持非水平地面。
- **把 LQR 反馈律作为一个「运动任务」塞进 WBC 的任务层级**，以此处理非最小相位动力学（**本文最核心的技巧，见下**）。
- **以 ZMP 为依据在线计算侧倾角参考**，提升过弯时的抗侧翻能力。

## 🔧 方法

### 动力学与闭环闭合

打开闭环后的无约束动力学为  
```  
M(q)·u̇ + b(q,u) + g(q) + s(q) = Sᵀ·τ  
```  
其中 `s ∈ R^{nu}` 专门表示**膝部两个扭簧**的作用（假定线弹性：角变形↔力矩），`S` 为选择矩阵（4 个电机对应哪些广义坐标）。广义坐标 `q ∈ R³ × SO(3) × R^{nj}`。

闭环通过在打开的铰点 P、Q 上引入**闭环力 F̃_L**（一对等值反向的轴承力）闭合，直接加入上式：  
```  
M u̇ + b + g + s + J_IP,Pᵀ·F̃_L − J_IQ,Pᵀ·F̃_L = Sᵀ τ  
```  
关键约束：**闭环力只能作用在闭环平面 Λ 内**（其法向 n_Λ 已被机构本身约束住）。

### WBC 任务层级（按优先级从高到低，共 6 项）

| 优先级 | 任务 | 说明 |
| --- | --- | --- |
| 1 | **Dynamics Task**（动力学任务） | 满足运动方程与接触约束，最高优先级 |
| 2 | **Base Height**（机身高度） | 加速度层 PD 律 |
| 3 | **Base Roll Angle**（机身侧倾角 ψ） | 参考值 `ref ψ` 由 ZMP 在线计算 |
| 4 | **LQR-Assisted Balancing** | **本文核心**，见下 |
| 5 | **Base Yaw Angle**（航向角 φ） | 控制行进方向 |
| 6 | **Torques Task**（力矩任务） | 最低优先级，力矩正则化 |

采用**分层二次规划（hierarchical QP）**，每一次迭代 i 加入一个任务，任务定义为线性等式 `A_i x = b_i`。

### ★ 核心洞察：为什么标准 WBC 在两轮平衡机器人上会失败

作者给出了一个极其清晰的论证：

> 为使机身从直立位姿**向前加速**，轮子必须**先向后加速**以获得足够的俯仰角，然后才向前加速，否则会向后倒。而标准形式的 WBC 只会沿着**期望运动方向**直接计算加速度，因此**无法复现这一行为**。

这正是非最小相位系统的本质：**期望输出方向与初始控制方向相反**。解法是引入 LQR 反馈律给出期望的俯仰角加速度：  
```  
des θ̈ = k_θ(ref θ − θ) + k_θ̇(ref θ̇ − θ̇) + k_v(ref v − v)  
```  
控制器于是会**先向后倒车一小段再向前加速**——即用 LQR 把"该往哪个方向先动"这一非最小相位知识**注入 WBC 的任务集合**。

为把 `des θ̈` 表达成 WBC 任务，作者借用**平均角动量（average angular momentum）**概念，把除两个轮子外的所有刚体（n_bod − 2 个）**集总（lump）为一个等效摆体 Π**：  
```  
I_Π · ω_IΠ = Σ_{K=1}^{n_bod−2} I_K · ω_IK  
```  
从而得到集总转动雅可比 `J_IΠ,R`，任务写为  
```  
A₄ = [ N J_NΠ,R^{(2)}  0 0 0 ],   b₄ = des θ̈ − N J̇_NΠ,R^{(2)} u  
```

### ZMP 调节的侧倾参考

过弯时侧翻风险上升。作者在线计算侧倾角参考，使 **ZMP 落在支撑线（Line of Support, LoS）的中心 G**。作者特别注明（脚注 10）：也可以直接加一个"两轮法向力相等"的任务来居中 ZMP，但**选用当前方式是为了能调节"倾斜激进程度"**，且必要时还可作为软约束加入 WBC 目标。

### 状态估计

IMU（含内置滤波器）+ 4 个电机的旋转编码器 → 运动学重建状态。绝对位置 `r_IB` 与速度 `v_IB` 通过**以左轮接触点为参考的轮式里程计**估计，**假定始终保持地面接触**。

### 不等式约束

- 静摩擦锥边界（假定摩擦系数 **μ = 0.8**，典型轮胎-路面工况）
- 防止轮子"向地面拉拽"：`F_C^{(2)} ≤ 0`、`F_C^{(4)} ≤ 0`

### 求解器与实时性

- QP 求解器：**OSQP**；LQR 的 DARE 求解：**Control Toolbox**
- QP 与 DARE 均用上一时步解**自动热启动（warm-start）**
- 控制频率 **400 Hz**，平均控制周期 **1.56 ms**，其中：
- **1.20 ms** 分层 QP
- **0.11 ms** 模型求值
- 余量为 DARE、状态估计与程序开销

## 🧪 实验

| 实验 | 设置 | 结果 |
| --- | --- | --- |
| **1. 冲击鲁棒性** | 2 kg 重物系绳从相对高度 1 m 落下，产生水平冲击 | 旧的基于 LQR 的控制器**直接无法稳定**；本文 WBC 从扰动中恢复，**T90 时间约 1 s** |
| **2. 地面高度自适应** | 右轮放在被人手上下移动的木板上（不可预测、非周期扰动） | 仅通过要求 **ψ = 0**，机器人即自动调整腿伸展量以适应高度变化——左腿伸展 ϕ₁ 几乎恒定在 **1.8 rad**，右腿 ϕ₂ 紧密跟随扰动。**柔顺性是任务设计的自然结果，而非专门设计** |
| **3. ZMP 调节过弯** | 对比 `ref ψ = 0` 与 ZMP 动态调节 | ZMP 调节使过弯**显著更平稳** |
| **静态能力** | — | 单轮可稳定站在 **0.20 m 高台阶**上（此时左腿四连杆接近**完全伸展**）；可在草地斜坡上行驶 |

**PD 增益调参说明（脚注 14）**：任务 2/3/5 的 PD 增益逐个调；任务 4 的 LQR 代价按其 2019 年工作的方式调，因为简化状态空间模型 (36) 是完整模型的一个子集。

### 4. 对第 7 章调度器的启示：分层 QP 的优先级 ≠ 你的专家调度

本文的"分层"是**同一时刻多个任务按优先级投影求解**（严格零空间投影），而你的"分层"是**不同时刻选择不同专家**。二者名字像但机制完全不同。

**但有一个可迁移的点**：本文任务层级中，**Dynamics Task 永远是最高优先级**（硬约束），其余为软目标。这提示你——在调度器之上，是否需要一个**永不被调度器覆盖的安全层**？例如电机力矩-转速可行域约束（`shin2023mor`）应当在任何专家被激活时都强制生效，而不是由各专家自行保证。这可以成为第 7 章「统一动作接口层」的一个具体职责。

### 5. 关于「非最小相位」——你的 RL 策略是怎么学到这个的？

本文最漂亮的论证是"想前进必须先后退"。**这恰好是一个可以写进大论文的绝佳对比论述**：

- 模型驱动路线：必须**显式**用 LQR 把这个知识注入任务集合，否则 WBC 直接失败；
- RL 路线：策略在试错中**隐式**习得该行为，无需人工告知。

> ★★★★★ **强烈建议在第 2 章或第 4 章加入这一对比**，并在实验中**验证你的策略确实学到了"先反向后正向"**：给一个阶跃前进速度指令，画出轮速与俯仰角的时间曲线，若出现初始负向轮速尖峰，即为直接证据。这是一个**成本极低、说服力极强、图非常好看**的实验，且是对 RL 可解释性的正面贡献。
