## 📋 基本信息

- **第一作者:** Haidong Hou（侯海东）
- **通讯作者:** Zhangguo Yu（余张国）— 北京理工大学
- **合作单位:** 北京理工大学（BIT）
- **平台:** 无手臂双轮足机器人（bipedal-wheeled robot without arms）
- **核心任务:** 无手臂双轮足机器人的跌倒恢复（fall recovery），仅靠腿部驱动力实现从各种摔倒姿态自主起身

## 🎯 研究目标

解决无手臂双轮足机器人的跌倒恢复难题：
1. **缺少支撑来源** — 无人形机器人的手臂、无四足机器人的多条腿辅助支撑
2. **仅靠双腿** — 必须仅通过腿部驱动力产生支撑力和力矩使机器人站起来
3. **从多种姿态恢复** — 侧倒、前倒、后倒等不同摔倒姿态

## 💡 核心贡献

1. **FTSR 框架（Force-guided Two-Stage Recovery）** — 两阶段力引导恢复框架
2. **力引导策略** — 利用足端力传感器反馈引导学习，而非仅依赖位置/姿态
3. **两阶段恢复** — Phase 1: 姿态调整（将身体调整到适合起立的构型）→ Phase 2: 站立起立
4. **sim-to-real** — 仿真训练后成功迁移到真实机器人

## 🔧 方法

### FTSR 框架

- **两阶段设计：**
  - **Stage 1（姿态调整阶段）**：通过腿部运动将身体从任意摔倒姿态调整到一个「可起立」的预备构型
  - **Stage 2（起立阶段）**：从预备构型用力驱动站立起来
- **力引导（Force-guided）**：策略网络输入包含足端接触力信息，让机器人学会利用地面反作用力来调整姿态

### 训练

- 使用 PPO 算法，在仿真中训练
- 状态空间：关节位置/速度、机身姿态（IMU）、足端力传感器
- 动作空间：腿部关节目标位置（PD控制器跟踪）
- 奖励函数：姿态调整奖励 + 起立成功奖励 + 能量效率惩罚

### 域随机化

- 对摩擦力、质量、惯性、关节摩擦力等进行随机化，实现 sim-to-real 迁移

## 🧪 实验

- **仿真环境：** Isaac Gym / 类似平台
- **真实机器人：** 无手臂双轮足硬件平台
- **测试场景：**
  1. 前倒恢复（face-down fall）
  2. 后倒恢复（face-up fall）
  3. 侧倒恢复（side fall）
- **结果：** 展示了对多种摔倒姿态的成功恢复，且能泛化到未见的摔倒姿势

## 💭 思考与延伸

这篇论文对你的**后空翻计划**来说是绝佳的**安全前置技能**：

1. **先学跌倒恢复** → 再学后空翻（训练空翻时机器人会疯狂摔倒）
2. **两阶段思路可直接复用**：后空翻也可以拆成「起跳→翻转→落地缓冲」
3. **力引导的思想**：你的 xqrobotwl 已有足端力/力矩传感器，可直接使用类似的力引导奖励
4. **轮子的额外优势**：你的机器人有轮子，倒地后轮子可以帮助滚动调整姿态

**建议的训练顺序：**
```
Phase 1: 跌倒恢复（FTSR）→ 任意摔倒都能站起来
Phase 2: 原地跳跃 + 安全着陆 → 已有 jump.py 基础  
Phase 3: 后空翻完整动作 → 飞跃翻转180°
```
