## 🎯 研究目标

已有两轮足爬楼梯工作**通用性极差**，难以适配不同硬件规格与复杂地形。关键痛点：**轮径决定爬台阶能力上限**——Chamorro 等在 Ascento 上（轮半径 25 cm）只能爬 15 cm 单级台阶，且必须给轮胎放气，也无法应对窄踏面连续楼梯。

目标：提出**与轮径/胎型无关的通用盲攀爬框架**，仅靠本体感知，让小轮径两轮足也能连续翻越远超其轮半径的障碍。

## 💡 核心贡献

1. **接触触发的 RL 任务框架** — 借鉴人类步态中的「接触触发反射」，以足端 xy 平面接触力触发抬腿状态切换，适配任意轮径/胎型。
2. **前馈轨迹指令学习** — 用一条基线抬腿轨迹作为启发信号「播种」抬腿原语，避免无效探索，大幅提升学习效率；训练后期**线性退火至零**，保证部署时策略自主执行。
3. **跨平台通用性** — Tron1 连续爬 **20 cm** 台阶（轮半径仅 11 cm，**约为轮半径的 1.8 倍、轮径的 1.6 倍**）；Cowarobot R0 连续爬 7.5 cm；同时保持平地快速移动能力。

## 🔧 方法

### 学习环境

- **Isaac Gym** 训练（GPU 大规模并行 + 域随机化），**MuJoCo 交叉验证**后再上真机——「MuJoCo 能过则真机大概率能过」。
- **地形**：8 m × 8 m，分 **10 列**（1 列光滑坡 + 1 列粗糙坡 + **6 列楼梯** + 2 列离散障碍）× **10 行**（课程难度递增）。
- 算法：**非对称 Actor-Critic PPO** + **MLP 状态估计编码器**；单张 RTX 4090（24 GB）。

### 观测与特权信息（Table I）

| 类别 | 内容 | 维度 | 噪声 |
|:---|:---|:---:|:---:|
| **观测（actor + critic）** | 角速度 | 3 | ±20% |
| | 投影重力 | 3 | ±5% |
| | 关节位置 | 6 | ±1% |
| | 关节速度 | 8 | ±50% |
| | 上一步动作（**网络原始动作与前馈动作的加权融合**） | 8 | 0 |
| **特权信息（仅 critic）** | 机身线速度 | 3 | — |
| | 平均接触力 | 6 | — |
| | 高度扫描 | 77 | — |

- 注意：**观测里没有机身线速度**（靠状态估计器推断），且关节速度噪声高达 ±50%。
- **「上一步动作」是融合后的复合动作**，这个细节很关键——让策略知道实际执行了什么，而不只是自己输出了什么。

### 动作空间

- 8 维：**腿关节 → 目标位置（PD 跟踪）**，**轮关节 → 目标角速度（速度控制模式）**。

### 接触触发机制（本文核心，三点增强）

**1) 阈值触发**：任一轮的接触力超阈值，立即激活前馈轨迹，先抬接触侧腿，对侧腿随后协同响应，形成交替上升。

**2) 滑动窗口滤波**：应对 Isaac Gym 刚体接触抖动，用**三帧滑动窗口**判定稳定接触：

```
C_t = Π_{i=0}^{2} 𝟙(F_{t-i} > τ)     τ ≈ 30 N（xy 平面接触力）
```

只有连续三帧都超阈值才算「稳定接触」，有效抑制高频噪声误触发。

**3) 轮腿协同耦合**：触发机制与滚动动力学紧耦合，实现连续滚动与离散迈步之间的无缝切换，兼顾能效与越障性能。

**抬腿优先级决策逻辑**：

| 情况 | 决策 |
|:---|:---|
| **单侧接触** | 该侧单腿抬起，另一侧维持支撑/驱动 |
| **双侧同时接触 · 仅一侧满足稳定接触** | **稳定优先**：抬那条，确保是真实物理障碍而非噪声 |
| **双侧均稳定接触** | **力大优先**：抬接触力更大的那条，最小化对机身的阻力矩，攀爬更敏捷 |

### 前馈指令学习（第二核心）

前馈轨迹**只注入髋 pitch 与膝 pitch 关节**：

```
a_t   = k_fb · a_π(t) + k_ff(n) · a_ff(t)
a_ff(t) = A · (1 − cos(2π t / T)),    T = 0.6 s
```

- 髋:膝 幅值比 **1:2**，用于起动基本抬腿动作。
- **刻意不把 A 设太大**：前馈的目标是「播种抬腿意图（seeds the lifting primitive）」，而非规定精确几何路径；具体抬腿高度由 RL 自行在交互中精化。
- **线性退火**：
  ```
  k_ff(n) = max(0, k_0 − n · k_0 / N_ann)
  ```
  训练推进中 k_ff → 0，前馈「脚手架」被完全移除，最终动作全由网络决定，保证 sim-to-real 无缝。

### 奖励（Table II 要点）

任务奖励含线/角速度跟踪（`exp(−20·误差²)` 形式）+ **基于位置进度的速度跟踪项（Δφ/Δt）** + 目标位置跟踪 + **足端空中时间**（`min(t_air, 0.5)`，仅首次触地计）+ **足端接触数**（符合期望相位 +1，不符 −1.3）+ **足端离地间隙**（摆动相且 h 在 [h_min, h_max] 内给奖）。

### 域随机化（Table III）

负载 [−0.5, 2] kg、质心偏移 ±3/±2/±3 cm、K_p/K_d 因子 [0.8,1.2]、**摩擦 [0.2, 1.6]**、**恢复系数 [0.0, 1.0]**、惯量 [0.8,1.2]、电机力矩 [0.8,1.2]、IMU 偏置 ±1.2、默认关节位 ±0.05 rad、**步延迟 [0, 20] ms**、推力间隔 8 s、推速 1.0 m/s。

> 作者特别说明：**摩擦与恢复系数用超宽范围**——宽摩擦让盲策略在各种真实地面都有可靠牵引；变恢复系数用于建模轮胎被动阻尼与撞击障碍边缘时不可预测的能量耗散。

### 两阶段训练课程

- **Stage I（探索）**：不约束足端横向/纵向落点，鼓励发现成功攀爬动作。
- **Stage II（精修）**：基于 Stage I 权重，加入「同足 x 位置」奖励规整前后运动，使姿态更优雅稳定。

## 🧪 实验

### 消融（4 配置 × 3 随机种子 × 80,000 iterations）

台阶高度 8 → 20 cm，踏面宽度同时 50 → 28 cm 递减。**成功率（%），100 并行环境 + 全域随机化**：

| 方法 | 8 | 10 | 12 | 15 | 18 | 20 | 22 |
|:---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **CTBC（完整）** | 100 | 100 | 100 | 98 | 96 | **86** | **70** |
| w/o 前馈 | 96 | 96 | 96 | 92 | 80 | 58 | 38 |
| w/o 接触触发 | 62 | 60 | 56 | 46 | 18 | **2** | 0 |
| w/o 两者（基线 RL） | 46 | 34 | 28 | 8 | 4 | 0 | 0 |

结论：
- **去掉接触触发最致命**（20 cm 处 86% → 2%）：无法把抬腿与真实触地同步，高障碍上灾难性失稳；只会重复抬腿，能耗高且不适应地形变化。
- **去掉前馈**：探索缺乏启发引导，地形等级推进慢、性能上限受限——前馈既加速收敛，也**提升越障能力上限**。
- **基线 RL 连最基本障碍都翻不过去**，证明两个组件缺一不可。

### 真机实验（Tron1，50 Hz，无任何外感知）

- **脱坑**：轮子掉入 **10 cm 深坑**，接触力越阈立即触发快速抬腿，即使控制回路离散在 50 Hz 也能平稳脱出不失衡。
- **爬台阶**：**16 cm 与 20 cm** 台阶，依撞击瞬间的瞬态接触力动态决定领先腿，盲态下快速上升且保持姿态稳定。
- **连续镂空台阶**：成功连续攀爬 20 cm **开放间隙（open-gap）楼梯**——支撑面极不连续且中空，难度更高。
- 作者提到：即使**跳过退火直接部署**，策略仍具一定可用性（说明前馈已被内化）。

## 🚀 可直接移植到 UniLab 的清单

1. **接触触发 + 三帧滑动窗口**（最高优先）
   ```
   C_t = Π_{i=0..2} 𝟙(F_xy(t−i) > 30N)
   ```
   刚体仿真的接触抖动是必然的，三帧窗口是最省事的滤波方案。你的 `stairs.py` / `toe_walk.py` 都该加。
2. **抬腿优先级：稳定优先 → 力大优先**。两轮足只有两条腿，这套二级判据几乎是照着你的构型写的。
3. **前馈轨迹只注入髋/膝 pitch，髋:膝 = 1:2，T = 0.6 s，`A(1−cos(2πt/T))`**，且**幅值刻意取小**（只播种意图）。
4. **前馈权重线性退火 `k_ff(n) = max(0, k_0 − n·k_0/N_ann)`** —— 这是「用前馈加速收敛」但「部署时不依赖前馈」的关键，比固定混合权重干净得多。
5. **「上一步动作」用融合后的复合动作**，不要用网络原始输出。
6. **两阶段课程**：Stage I 放开落点自由探索 → Stage II 加「同足 x 位置」奖励规整姿态。可推广为你所有专家的通用训练流程。
7. **摩擦 [0.2, 1.6] + 恢复系数 [0.0, 1.0] 的超宽随机化**，专门补偿盲策略的牵引不确定性与撞击边缘的能量耗散。
8. **Isaac Gym 训练 → MuJoCo 交叉验证 → 真机**的三段式验证流程（你用 MuJoCo + UniLab，可反向：MuJoCo 训 → 换引擎验证）。
9. **步延迟随机化 [0, 20] ms**：你在 200 Hz 高动态专家上尤其需要，真机通信延迟是空翻失败的隐形杀手。

## ❓ 待解答的问题

1. 前馈幅值 A 与退火步数 N_ann、k_0 的具体数值未在正文给出，需看项目页/代码。
2. 「接触力」在真机上如何获得？Tron1 有足端力传感器还是靠关节电流估计？（论文说仅本体感知，推测由电流/力矩反算）
3. 阈值 τ = 30 N 与平台质量强相关，换到你的 xqrobotwl 需要重新标定（建议按机身重量归一化）。
4. 50 Hz 控制频率对 20 cm 台阶已够，但你的高动态专家用 200 Hz，接触触发是否需要更高频的窗口（帧数是否要增加）？
5. 只做了上台阶，**下台阶**未涉及；而你第 5 章明确包含「上/下台阶成功率」，这是你可以做出增量的点。
6. 无地形感知 → 无法预判台阶高度，因此抬腿高度靠 RL 泛化。若加入你已有的地形感知，能否进一步提升 22 cm 以上的成功率？

## 💭 思考与延伸

**对你大论文最直接的三点价值**：

1. **第 5 章的对比基线有了**。CTBC 是当前两轮足盲爬台阶的 SOTA，且开了项目页。你的 N3PO 方案必须与它对比，或者更聪明的做法：**把接触触发作为你 N3PO 专家的状态机触发器**，二者结合（约束保安全 + 触发定时机），这样你的第 5 章既有对比又有融合创新。
2. **前馈 + 退火范式可复用到后空翻**。你第 6 章写的是「确定性翻转 + 前馈控制」，CTBC 给出了工程上更干净的做法：前馈只播种、权重退火到零。这比固定 FSM 前馈更利于 sim-to-real。
3. **「接触触发」是一种廉价的隐式调度**。你第 7 章的学习式调度器是全局的（选哪个专家），而 CTBC 证明局部时序决策（何时抬腿）用接触信号触发即可，不必都交给高层网络。**建议在第 7 章明确区分「全局专家调度」与「局部反射触发」两个层次**，这会让你的分层设计更有说服力。
