# 更新记录

## v1.2.0 — 2026-09-05

### 新增

- 新增全部片段全文搜索，支持大小写匹配、正则表达式、结果高亮和跨文件定位。
- 新增 `Ctrl/⌘+P` 快速打开文件，并与 AI、符号和搜索记录统一到搜索中心。
- 新增代码位置前进/后退导航、`Alt+F12` 定义预览和 `Alt+O` 同名头文件/源文件切换。
- 新增 VS Code 式 `Ctrl/⌘+单击` 跳转定义，覆盖函数、类型、宏、变量及多栏编辑器，并在按住修饰键悬停时提示目标。
- 新增 VS Code 式符号悬停卡片，停留约 550 毫秒后显示函数、类型、宏或变量的签名、定义位置和源码片段；卡片支持鼠标移入、横向/纵向滚动和长定义浏览。

### 优化

- 导航历史覆盖左侧选中、文件标签切换、多栏主编辑器切换和搜索结果跳转。
- 定义预览沿用当前主题的语法高亮，可继续打开完整定义，减少阅读时上下文丢失。
- 关系图曲线末端改为更小的实心三角箭头，提升方向辨识度并减少视觉重量。
- 代码补全改为仅按 `Ctrl/⌘+Space` 手动触发，普通输入和移动光标不再弹出遮挡代码。
- 本地时间线改为按连续编辑会话合并，两分钟内多次自动保存只保留一个会话起点，并折叠已有的相邻冗余记录。
- 版本接口补充代码阅读能力标识，自动化测试改为动态统计通过项。

## v1.1.0 — 2026-09-05

### 新增

- 新增 AI 搜索入口，支持项目符号检索、API 用法说明、示例生成以及 Tavily / Brave 实时联网搜索。
- 新增 2 至 4 栏拖拽编辑，可并排打开多个源码文件并让右侧阅读面板跟随当前编辑栏。
- 新增编辑器查找与替换快捷键、五套工作台主题和 GitHub 仓库入口。

### 优化

- 重构调用关系图的节点层级、拓扑布局、连线和空状态展示。
- 修复多栏编辑的高亮遮挡、空白辅助栏及恢复单栏后 Markdown / LaTeX 预览缺失问题。
- 完善远程工程文件传输、窗口缩放、SSH / VNC 交互和连接延迟展示。
- 优化 LaTeX 单页简历模板、嵌入式 Linux 技能分组和荣誉经历排版。

## v1.0.0 — 2026-09-04

码境 CodeScope 首个正式版本。

### 核心能力

- 支持代码片段、Markdown、LaTeX 工程与绘图文件的统一管理和编辑。
- 提供代码大纲、符号定位、引用检索、调用关系图和树形关系浏览。
- 支持多文件 C/C++ 等代码的运行、检查、格式化及交互式终端。
- 提供 Markdown 实时预览、思维导图及 PNG/SVG 导出。
- 提供 LaTeX 工程目录、资源管理、实时编译和 PDF 预览。
- 集成环境检测、一键部署、CPU/内存/磁盘状态监测。
- 集成 SSH 交互终端与 VNC 远程桌面，支持输入法、窗口适配和网络延迟显示。

### 平台与兼容

- 支持 macOS、Linux/WSL 和 Windows 启动与环境配置。
- 新增 `CODESCOPE_HOST`、`CODESCOPE_PORT`、`CODESCOPE_VAULT` 配置。
- 继续兼容既有 `MASSCODE_*` 环境变量及 massCode Markdown Vault。
